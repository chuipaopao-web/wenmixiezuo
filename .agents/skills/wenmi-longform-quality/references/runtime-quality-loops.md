## 模式路由

先路由模式，避免把创作探索变成流水线审批：

```text
开放讨论 → 对话/开放问题，不写正史
创意推演 → 多个独立候选，不提前压成共识
暂存试写 → 临时稿/多版本，不强制全套审校和结算
正式生产 → 完整准备、生成、审校和结算
```

只有正式生产使用下列完整流程。前三种模式仍遵守版权、安全、费用、书籍隔离和永久操作边界，但不得因为缺章纲而阻断发散或试写，也不得自动把产物提升为正式层。

## 正式生产流程

```text
作者讨论
→ 两名异模型编剧独立检索、意见与章节跨度估算
→ 设定硬矛盾检查
→ 主编形成候选方案和异议
→ 作者确认方向
→ 分层规划与写作工单
→ 主笔或副笔中的单一活动写手按场景生成
→ 硬检查与事实/文学/体验三异模型全文点评
→ 主编合并单一定点修改单
→ 定点重写或上游返工
→ 作者确认正文
→ 正史结算与派生投影更新
→ 纵向质量监控
```

正式正文入口不得绕过资料准备、三点评和结算门禁。Agent之间通过可审计产物交流，不假定存在零成本、零噪声心灵通信；双编剧和三点评席的独立意见完成前禁止共享其他岗位结论造成锚定。

## 十个回路

### 1. 正史回路

- 输入：作者确认决定、已结算正文、正式设定和规划版本。
- 输出：带来源、故事时间、适用范围和状态的事实；不可变正文版本。
- 权威：正式正文与确认决定；Wiki、摘要、向量只做派生投影。
- 转换：临时→候选→复核/确认→生效→失效但保留历史。
- 停止：来源不明、重大冲突、人物生死/核心规则改变或结算不原子。

### 2. 检索回路

- 输入：任务类型、章节、故事时间、实体、关系、目标和Token预算。
- 输出：最小充分的来源清单、采用理由、排除理由、置信度和原文指针；不是召回越多越好。
- 权威：正史结构化事实和正式原文。
- 转换：查询理解→候选召回→范围过滤→融合重排→证据回查→约束胶囊/灵感调色板分组→采用记录。
- 停止：检索为空、证据冲突、旧版本占优、无答案却要求确定结论。

### 3. 注意力回路

- 输入：岗位、任务书、检索候选和硬约束。
- 输出：岗位专用不可变上下文包，明确硬约束、任务目标、软倾向、自由创作区和重大候选。
- 权威：任务书和硬来源优先于相似度。
- 转换：去重→按作用分组→预算分配→排序→必要压缩→哈希冻结。
- 停止：硬来源超预算、关键证据被压缩掉、同一事实出现冲突版本、软规则挤空自由创作区。

### 4. 规划回路

- 输入：创作方案、故事圣经、总纲、已结算正史和开放问题。
- 输出：卷纲、近期章纲、场景目标、可选节拍、承诺—兑现、自由创作区和影响范围。
- 权威：作者确认的活动规划；远期计划不是已经发生的事实。
- 转换：远期粗计划→近期细化→章节结算反馈→受控修订→依赖失效。
- 停止：重大主线分叉、人物命运改变、修改影响多卷但未评估；合理的局部实现偏离不自动停止。

### 5. 人物回路

- 输入：人物事实、行为证据、关系、知情边界、欲望和历史原文。
- 输出：当前状态、声音证据、允许变化和疑似漂移。
- 权威：正式正文行为证据高于标签式总结。
- 转换：事实提取→证据聚合→时间切片→分析视图→正文验证。
- 停止：硬状态矛盾、人物掌握不可能信息、成长缺少可见原因。

### 6. 生成回路

- 输入：写作工单、场景契约、当前状态、人物声音、允许伏笔和必要原文。
- 输出：完整暂存章节、新增事实候选和有理由的契约偏离说明。
- 权威：工单与正史；主笔不得直接修改正式层。
- 转换：硬预检→场景整体构思→连续生成完整草稿→章节整合→格式/硬约束后检→暂存。软审美检查不得插入逐句生成。
- 停止：硬资料缺口会改变主线、上一章未结算、上下文与工单硬冲突；自由创作区的局部空白不停止。

### 7. 三点评回路

- 输入：同一不可变完整稿、写作契约、前章结尾、硬检查结果、活动写手模型来源，以及事实/文学/体验三席各自最小附加资料。
- 输出：三份带版本、模型、位置、严重度、证据和修改目标的独立报告；Kimi额外输出AI腔风险及标记段落占比，豆包额外输出政治/情色风险及策略版本。
- 权威：闭环硬事实、安全与合规项可阻断；文学软判断必须有正文证据且不能按多数票冒充事实。AI腔分数不是AI作者概率，内容风险不是法律/平台保证。
- 转换：完整草稿→确定性硬检查→三席并行→主编合并一张修改单→定点重写或保留原稿→新版本三席复核→通过或上游返工。
- 停止：任一席缺失/重复/与写手同模型、GLM写手未切换DeepSeek事实席、blocker、两轮修订无效、问题根因在章纲，或软修改让整体输出低于原稿。

### 8. 结算回路

- 输入：作者/主编接受的正文版本、事实候选和审校结果。
- 输出：正式正文、正史事实、章末状态、投影更新和失效事件。
- 权威：选中正文哈希和结算事务。
- 转换：事实分类→冲突检查→分级门禁→原子登记→索引/ Wiki重建队列。
- 停止：正文和事实不能原子对应、重大候选未确认、派生失效传播失败。

### 9. 作者治理回路

- 输入：作者要求、当前事实、Agent独立意见和影响分析。
- 输出：推荐、最强反对理由、结构不同的备选、少数高潜意见、影响和需确认决定。
- 权威：作者决定创作方向；事实正确性和系统安全不以迎合为准。
- 转换：意图识别→相关岗位差异化检索→独立意见→主编综合→异议/备选保留→作者裁决。
- 停止：模糊确认、观点与正史冲突、选择会永久改变重大方向。

### 10. 纵向质量回路

- 输入：已结算章节、章末状态、伏笔、节奏、人物声音和审校趋势。
- 输出：跨章缺陷、创造性/同质化趋势、上游调整建议和基线非劣效评测记录。
- 权威：正式章节与独立盲评；单次模型自评分只作观察。
- 转换：窗口聚合→异常检测→证据抽样→独立复核→调整规划/模型/契约。
- 停止：指标与人工盲评方向相反、同类major连续出现、缺陷无法局部修复，或可靠性提高但创造性/整体质量退化。

## 经验进化横向回路

Agent不靠无限聊天记忆“进化”。可复用经验按以下流程沉淀：

```text
真实失败或成功差异
→ 形成经验候选
→ 记录适用范围、反例和禁止外推
→ 跨样本验证
→ 主编/老板确认
→ 版本化启用
→ 观察基线差异
→ 到期复核、降级或撤销
```

单次采纳、一次改写、模型自评分和没有反例的技巧不能成为永久规则。经验只能影响对应题材、岗位和阶段；不得把所有岗位统一成同一种安全写法。

## 粒度边界

- 局部文字质量：句子、对白、动作、意象和重复。
- 章节质量：目标、冲突、转折、代价、情绪和钩子。
- 跨章连续性：事实、人物、因果、承诺和伏笔。
- 全书叙事质量：主题、结构、人物弧、节奏和信息控制。
- 作者满意度：个人选择，不自动等同于前四项质量。

验收必须说明测量哪一层，不得用局部流畅度代替全书质量，也不得用一致性平均分抵消原创性、人物、情绪或整体阅读质量下降。
