## 1. 模式路由

先路由模式，避免把创作探索变成流水线审批：

```text
上下文协作 → 围绕当前对象交流与选择，不写正式层
创意推演 → 多个独立候选，不提前压成共识
暂存试写 → 临时稿/多版本，不强制全套审校和结算
正式生产 → 完整准备、生成、审校和结算
```

模式不绑定独立聊天页。协作可以发生在资料、设定、阶段、事件、章纲或正文旁边，但必须保存作者原话、对象定位、参与能力、任务状态和结果引用。

模式路由前只做确定性受理：控制命令直接处理；点名请求直达当前合同允许的成员；创意请求进入相应创作能力；资料请求保留原件并产生候选。受理层不得替代创作成员给结论，也不得按消息长度判断风险。

只有正式生产使用完整流程。前三种模式仍遵守安全、来源与原创性风险、费用、书籍隔离和不可逆操作边界，但不得因缺少完整规划而阻断，也不得自动提升到正式层。

## 2. 正式生产流程

根据当前产品合同启用必要步骤，不写死具体成员和模型：

```text
作者在当前对象旁提出目标或修改
→ 必要创意能力独立形成候选
→ 统筹能力保留差异并给出推荐
→ 作者确认方向
→ 当前卷纲/事件大纲/可选节拍/当前事件章纲与写作任务
→ 单一活动写手生成完整草稿
→ 硬检查与事实/文学/体验独立审校
→ 定点修改或返回上游
→ 作者确认正文
→ 正式正文、正史结算和派生更新
→ 事件/阶段状态与纵向质量更新
```

正式正文不得批量越过逐章版本、审校、作者确认和结算。可以批量准备候选或章纲，但下一章正式生产必须读取上一章最新结算状态。独立意见完成前禁止共享其他成员答案造成锚定。

## 3. 十个质量回路

### 3.1 权威回路

- 输入：作者确认决定、正式正文、正式设定和活动规划。
- 输出：带来源、故事时间、适用范围和状态的事实及不可变正文版本。
- 权威：正式正文和确认决定；Wiki、摘要、事件卡和向量只做派生或规划。
- 停止：来源不明、重大冲突、人物生死/核心规则改变或结算不原子。

### 3.2 检索回路

- 输入：模式、任务、对象、故事时间、实体、关系和Token预算。
- 输出：最小充分来源、采用/排除理由、置信度和原文指针。
- 转换：查询理解→多路召回→范围过滤→融合重排→证据回查→约束/灵感分组→上下文包。
- 停止：检索为空、证据冲突、旧版本占优、无答案却要求确定结论。

### 3.3 注意力回路

- 输入：被激活能力、任务书、检索候选和硬边界。
- 输出：能力专用不可变上下文包。
- 处理：去重、按作用分组、预算、排序、必要压缩和哈希冻结。
- 停止：硬来源超预算、关键证据被压掉、冲突版本并存未标记或自由创作区为空。

### 3.4 规划回路

- 输入：开书信息、作品主脉、作者原始想法、活动设定、上一卷结算、当前卷纲、已结算正文和开放问题。
- 输出：当前卷目标与节奏、事件大纲、可选模板节拍、当前事件的近期章纲、下一卷接口、自由创作区和影响范围。
- 权威：作者确认的活动规划；预计跨度和远期方向不是已发生事实。
- 处理：保留作者原话→讨论并确认设定→用白话节奏卡形成结构差异明显的卷纲候选→作者选择/混合/编辑→当前卷事件链→逐个事件节奏→当前事件章纲→正文反馈→卷结算→用前卷后果设计下一卷。
- 停止：重大主线分叉、人物命运改变、事件/章纲脱离活动卷纲、作者想法被摘要替代、模板在卷纲与事件层重复套用、恒定高潮挤空张弛与人物余波、固定模板挤空创作自由或修改影响未评估。

### 3.5 人物回路

- 输入：人物事实、行为证据、关系、知情、欲望和历史原文。
- 输出：当前状态、声音证据、允许变化和疑似漂移。
- 权威：正式正文行为证据高于标签总结。
- 停止：硬状态矛盾、人物掌握不可能信息、成长缺少可见原因。

### 3.6 生成回路

- 输入：写作任务、当前状态、人物声音、允许线索和必要原文。
- 输出：完整暂存章节、新事实候选和有理由的任务偏离。
- 处理：硬预检→整体构思→连续生成→格式/硬约束后检→暂存。
- 停止：硬资料缺口改变主线、上一章未结算、上下文与任务硬冲突；自由区局部空白不停止。

### 3.7 审校回路

- 输入：同一不可变完整稿、写作任务、前章结尾、硬检查和写手模型来源。
- 输出：事实、文学、体验三维报告，均带位置、严重度、证据和修改目标。
- 独立性：三维可由当前合同规定的成员承担，但真实模型来源均与写手不同，提交前互不可见；硬证据不按多数票消除。
- 处理：硬检查→独立并行→合并修改单→定点重写/保留原稿→必要复核→通过或上游返工。
- 停止：维度缺失、模型重复、blocker、修订无效、根因在上游或软修改让整体质量低于原稿。

### 3.8 结算回路

- 输入：作者接受的正文版本、事实候选和审校结果。
- 输出：正式正文、正史事实、章末状态、事件/阶段进度、投影更新和失效事件。
- 权威：选中正文哈希和结算事务。
- 停止：正文与事实不能原子对应、重大候选未确认或派生失效传播失败。

### 3.9 作者治理回路

- 输入：作者原话、当前事实、独立意见和影响分析。
- 输出：推荐、反例、必要备选、少数高潜意见、影响和待确认决定。
- 权威：作者决定创作方向；事实正确性和系统安全不以迎合为准。
- 停止：模糊确认、与正式事实冲突或选择会永久改变重大方向。

### 3.10 纵向质量回路

- 输入：正式章节、章末状态、事件闭环、开放承诺、节奏、人物声音和审校趋势。
- 输出：跨章缺陷、同质化趋势、上游调整建议和基线非劣效记录。
- 权威：正式章节与独立盲评；单次模型自评只作观察。
- 停止：指标与盲评相反、同类重大问题连续出现、缺陷无法局部修复，或可靠性提高但创作质量退化。

## 4. 经验进化

不要靠无限协作记录让成员“进化”。使用：

```text
真实失败或成功差异
→ 经验候选
→ 适用范围、反例和禁止外推
→ 跨样本验证
→ 老板或治理流程确认
→ 版本化启用
→ 基线观察
→ 到期复核、降级或撤销
```

单次采纳、一次改写、模型自评分和无反例技巧不能成为永久规则。工具层经验只覆盖检索、路由、上下文、状态和故障处理；不得沉淀作者剧情偏好画像或建立与单书权威竞争的事实库。

## 5. 粒度边界

- 局部文字：句子、对白、动作、意象和重复。
- 章节：目标、冲突、转折、代价、情绪和钩子。
- 节拍：卷纲或事件模板实例中的叙事职责、白话引导问题和预期变化；可以合并、拆分、重排或跳过，不等同于一章。
- 事件：跨章因果闭环、起止状态、结果和下一接口；仅在适用时存在。
- 卷纲：当前一卷的起止状态、目标、事件链、人物变化、高潮阶梯、卷末余波和下一卷接口。
- 作品主脉：开书信息中的故事核心、结局方向、主题、长期人物弧、承诺和信息控制；只提供跨卷方向，不提前细化所有卷。
- 作者满意度：个人选择，不自动等同于前述质量。

验收说明测量层级。不得用局部流畅度代替全书质量，也不得用事件完成率或一致性平均分抵消原创性、人物、情绪和整体阅读质量下降。
