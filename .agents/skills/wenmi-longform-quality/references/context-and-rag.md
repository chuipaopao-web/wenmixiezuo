## 1. 权威分层

| 层 | 内容 | 默认检索 | 是否权威 | 生命周期 |
|---|---|---|---|---|
| 正式源 | 已确认正文、设定、规划、决定和正史事实 | 是 | 是 | 不可变版本；可失效但不覆盖历史 |
| 临时源 | 协作记录、初稿、重写稿和中间推演 | 仅当前任务 | 否 | 有界保留或归档 |
| 候选源 | 待确认事实、研究结论和规划提案 | 按任务显式 | 否 | 确认后进入对应正式层，否则失效 |
| 派生Wiki | 人物、地点、组织、规则、事件和开放线索页面 | 是 | 否 | 从正式源重建，带版本与来源 |
| 检索索引 | FTS/BM25、向量、关系邻接和时间投影 | 是 | 否 | 可删除、可重建、不能决定正史 |
| 上下文包 | 某次能力调用实际采用的资料 | 仅追溯 | 冻结快照 | 依赖变更后失效，不静默改写 |

协作记录不是长期权威。协作中形成的决定、设定或偏好必须结构化并按对应规则确认，才能进入正式层。检索遵守“最小充分”而不是“越多越完整”；召回到不等于必须注入或使用。

## 2. 检索流水线

```text
模式、任务与能力识别
→ 查询解析（实体、别名、关系、故事时间、意图）
→ 硬范围过滤（owner/book/版本/状态/权限）
→ 多路召回
   ├─ 结构化事实与时间状态
   ├─ FTS/BM25精确文本
   ├─ 向量语义候选
   └─ Wiki/关系多跳扩展
→ 证据去重与冲突检测
→ 融合与能力重排
→ 正式事实/原文回查
→ 约束胶囊与灵感材料分离
→ 预算和最小充分排序
→ 不可变上下文包
```

超长篇先建立活动工作集：全书主脊、当前阶段、当前事件（如适用）、上一结算、实体当前状态和开放线程。已闭合旧阶段原文默认休眠；实体、开放承诺、规则、知情/关系/声音证据、历史因果、摘要冲突或作者回顾触发时，再按阶段→事件→章节/场景→正式事实/原文逐级下钻。

摘要只导航，不成为事实源。不要用固定最近N章或固定相似度阈值替代时间、权威、实体和关系判断。

## 3. 通道职责

- 结构化查询：生死、位置、数量、知情、关系、归属、故事时间和规则状态。
- FTS/BM25：姓名、专名、原句、口头禅、明确关键词和正文定位。
- 向量：无关键词重合的语义改写、主题、情绪、行为和风格候选。
- 关系链接：人物—地点—组织—事件—规则—开放线索的多跳扩展。
- 时间过滤：区分现在、过去、计划、失效、谎言和人物认知。
- 融合重排：结合硬边界、能力意图、来源权威、时间有效性和通道分数；不只看向量相似度。
- 原文回查：重要结论定位正式事实或正文；Wiki、摘要和向量不得成为唯一证据。
- 创意去锚：相似场景和风格原文只作少量候选，必要时先构思再定向回查。

一次初始检索后最多进行有界补充；记录本地候选量、模型注入量、采用与排除理由。硬事实和开放线程不按章节距离自动遗忘。

## 4. 五级输入

每个上下文包区分：

1. 硬事实：正式事实、当前状态、故事时间及硬边界。
2. 任务目标：必须产生的叙事功能和结果，允许不同实现。
3. 软倾向：风格、节奏、气质、题材和建议节拍，可有理由偏离。
4. 自由创作区：未指定的对白、动作、细节、意象、调度和过渡。
5. 重大候选：允许探索但正式结算前需确认的新规则、命运和主线变化。

硬事实和任务目标组成约束胶囊；少量人物声音、主题、意象和开放线索组成灵感材料。软倾向不得伪装成硬规则。自由创作区为空时退回任务或上下文组装。

## 5. 能力上下文

从当前产品合同读取实际成员和模型，再按能力组包：

| 能力 | 必需来源 | 可选来源 | 默认禁止 | 二次回查条件 |
|---|---|---|---|---|
| 方向统筹 | 作者最新原话、活动决定、当前任务、独立意见 | 关键正式事实、预算、历史决策 | 全部正文、无关记录、把人数当共识 | 意见冲突、重大方向、接管或证据不足 |
| 独立创意 | 活动规划、人物欲望、已结算事件、开放线索、当前目标 | 历史因果链和少量题材灵感 | 另一席初始答案、全部协作记录、旧套路全集 | 新路线与事实冲突、转折依赖未知规则 |
| 设定/连续性 | 类型化事实、时间线、人物状态、规则和来源 | 相关原文、候选冲突 | 无来源摘要、失效投影、把空白当错误 | 同名实体、时间不可能、规则版本冲突 |
| 活动写手 | 写作任务、约束胶囊、前章状态、人物声音、自由创作区 | 灵感材料、少量风格原文和允许线索 | 整本书、全部讨论、废稿、另一写手解释 | 硬动机/声音缺证据、线索含义不明 |
| 事实审校 | 完整当前稿、任务、正式事实和相关原文 | 冲突候选 | 写手解释、无来源摘要 | 证据两端不完整或存在多种自洽解释 |
| 文学审校 | 完整当前稿、任务和少量人物声音 | 重复趋势、旧版本对照 | AI作者判断、无证据偏好、边写边审 | 风险可能是有意文体或人物差异 |
| 体验审校 | 完整当前稿、题材承诺和内容尺度 | 阶段节奏和情绪趋势 | 固定爽点模板、全部历史反馈、法律/平台保证 | 风险依赖题材、地区、平台或上下文 |
| 按需研究/来源保护 | 明确问题、来源、授权、时间/地区和风险维度 | 多种解释、类型惯例、独立表达证据 | 无关资料堆积、受保护原文进入写手包 | 来源冲突、授权不明或实质性相似难判断 |

上下文由可审计服务编译，不由某个拟人角色垄断数据库和向量库。成员只能通过受控接口取得岗位包，不能直接修改权威数据。相同工具或模型承担多种能力时如实披露，不计为多份独立意见。

上下文协作入口只保存一次作者原话，并携带当前对象引用。页面投影可以不同，但不能复制出多个事实源。取消独立聊天页时仍保留消息、附件、讨论、任务和调用证据的兼容读取。

## 6. 排序与失败处理

排序优先级：

1. 模式、任务、输出合同和硬禁止项。
2. 当前章节/场景状态与正式事实。
3. 自由创作区和待确认重大候选。
4. 查询直接证据。
5. 少量必要原文和人物声音。
6. 可选灵感、可撤销经验和备选。

去除重复表达但保留真实冲突。压缩带原文指针、方法和丢弃说明，不通过重复硬规则提高表面权重。

- 检索为空：说明缺口；允许新增时标候选，否则停止。
- 证据冲突：同时返回来源、版本和时间，不由相似度静默裁决。
- 旧版本命中：排除或标记历史用途。
- 低置信度：扩大一轮关系/原文回查；仍不足时升级。
- 上下文超限：先删重复、低权威、远期和无关资料；硬来源仍超限则暂停。
- 无答案：回答不足以判断，不用最相似片段填空。
- 过度召回或旧文锚定：减少相似材料，保留硬事实后重试，并做盲评。
- 摘要遗漏：逐级回查正式事实/原文；无依据时报告未知。

## 7. 验证要求

- 查询集与实现独立，不用内置同义词生成金标。
- 分通道报告召回、精度、MRR/nDCG、无答案、延迟和Token并做消融。
- 比较融合、单一FTS、单一向量和整书上下文。
- 比较最小充分包、全量包和无软资料基线的约束遵循、原创性、人物、情绪和整体质量。
- 验证索引损坏可由正式源重建，跨书污染为零。
- 在超长篇后期触发早期实体、规则、承诺和因果，验证按需回查而非固定遗忘。
- 验证上下文协作在切页、刷新、重启、超时和结果不明后不丢原话、不重复任务。
- 验证来源和原创性保护在无独立页面、无固定岗位时仍能阻止受保护原文直接进入正式生成。
