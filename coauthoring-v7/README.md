V7 已经上线并成为唯一当前产品。本目录包含 V7 作者端、独立后台、后端能力、产品文档和开发工单。

- 作者端：`author-web/`
- 独立后台：`admin-console/`
- V7后端：`backend/`
- 生产作者端：`https://wenmixiezuo.com/`
- 生产独立后台：`https://admin.wenmixiezuo.com/`

V7 复用统一账号、会员、反馈、安全、用量、数据库、任务、备份和部署底座，但不读取或展示旧版书籍、资料库、正文和工作流。

## 权威顺序

1. 老板最新明确决定；
2. 根目录 `AGENTS.md`；
3. 根目录 `HANDOFF.md` 与本目录 `HANDOFF.md`；
4. 当前唯一开发工单；
5. 当前代码、数据库和运行证据。

历史工作单和 Git 历史只用于追溯。已合并迁移和历史表名必须保持字节兼容，但不代表旧产品仍然存在。

## 当前清理要求

- 禁止重新引入旧版页面、旧版作者 API 或旧版创作流程。
- 共享能力使用中性或 V7 命名；历史数据库对象保持兼容。
- 本地作者数据的永久清理必须经过影响预览和双确认。
- 生产数据以服务器为准；本地数据不得作为生产恢复来源。
