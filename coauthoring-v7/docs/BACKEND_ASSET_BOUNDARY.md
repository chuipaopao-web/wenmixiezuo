# V7 后台资产边界

> 状态：V7 已上线。本文件只说明当前共享平台能力、V7产品能力和不可改写历史的边界。

## 一、当前共享平台底座

以下能力由 V7 继续使用，不属于旧产品页面或旧创作流程：

- 登录、会话、管理员权限与账号安全；
- 会员等级、有效期、用量记账和服务端门禁；
- `owner_id + book_id` 隔离；
- 数据库迁移、备份、恢复、健康检查和回滚；
- 任务、模型快照、预算、幂等调用、失败重试与审计；
- 正文不可变版本、正史事实、来源、结算和知识投影；
- 结构化、全文和关系检索以及 ContextPack 预算；
- API Key 仅来自环境变量的安全边界。

这些共享能力可以保留内部历史表名和迁移号。历史名称是数据兼容标识，不是旧版产品入口，不得为了“看起来全新”而改写已合并迁移或生产表。

## 二、V7 产品能力

V7 当前产品代码位于 `coauthoring-v7/`，通过 V7 路由和共享平台合同运行：

- 作者端：首页、开书、设定、时光机、卷、链、章、资料库、任务和团队；
- 独立后台：运营、用户与会员、成本与用量、创作资产、成员/岗位/模型、提示词与上下文、任务追溯、功能台账；
- Agent节点：节点任务合同、题材工位提示词、Skill、ContextPack、PromptManifest、生成、审查、结算和增量维护；
- 创作事实：候选、作者确认规划、正文实际和结算实际严格分区。

V7 不导入旧作者端组件，不注册旧创作API，也不把旧版书籍、资料库、正文或任务投影到当前书架。

## 三、源码命名与兼容规则

当前运行源码使用中性或 V7 名称。此前沿用旧版本文件名的共享合同、Skill、节点模板和核心服务已经迁移到中性路径。

允许继续存在的旧版本标识仅限：

- 已合并迁移文件名；
- 迁移创建且生产仍使用的表名、列名和外键；
- 已完成任务快照中的 Skill、模板和策略版本 ID；
- 历史工单和 Git 提交中的审计文字。

这些标识不得被新代码当成产品版本开关，也不得成为恢复旧页面或旧工作流的依据。

## 四、ContextPack 与创作资料

ContextPack 继续使用结构化、全文和关系召回，但每个节点只读取本次任务的最小充分资料。系统处理身份、版本、哈希、预算和来源；Agent处理语义理解、相关性、冲突、创作和文学判断。当前运行不装配本地向量模型或外置向量库。

不得一次向成员发送整本书或重复大包。正式设定、卷、链、章和正文都使用版本化摘要与必要证据；超限时拆层、拆批或停止，不静默截断。

## 五、尚未完全独立的能力

正史、关系、时间线和多种检索投影已经存在；完整独立 Wiki 产品仍未作为已交付功能对外承诺。需要时可以从正式证据建立投影，但不能把候选规划冒充正文实际。

## 六、旧实现清理原则

删除对象必须同时满足：

1. 当前 workspace、启动、路由、动态注册、任务恢复和部署均无有效引用；
2. V7已有相同或更完整的纵向闭环；
3. 相关账号、会员、正式作者数据和回滚能力不受影响；
4. 源码删除后定向门禁和全量门禁通过。

本地作者数据、数据库备份和浏览器档案属于永久删除范围时，必须先给出精确影响预览，再执行 `YES` 和 `CONFIRM:<previewId>` 双确认。生产数据不在当前本地清理范围内。
