## 设计与验收

采用 PostgreSQL 事务队列、SKIP LOCKED 领取、单调租约令牌和持久检查点；新合成任务增量表与已有生产数据完全隔离。拒绝以进程内状态或单纯重启整个任务替代恢复。外部调用不具备原子性，必须记录开始及未知结果；测试只模拟，不实际调用外部服务。

1. 同范围重复入队不重复任务；不同请求不能错误共享结果；跨 owner/book 访问拒绝。
2. 两个独立 Worker 并发处理，无重复有效提交；过期持有者续租、检查点和完成操作被拒绝。
3. 进程退出后从最后成功检查点恢复；执行中未知外部结果不自动重发。内部合成核对入口绑定调用身份与待核对版本：确认已有结果则接续，确认未执行才允许有上限重试；无核对证据继续保持待核对。
4. 取消、重试上限、不可恢复失败、数据库事务失败均有持久真实状态；不吞错冒充成功。
5. 任务结果与事件原子提交，事件按游标可回放，不暴露模型思维链或凭据。
6. 在真实隔离 PostgreSQL 空库迁移、重复迁移及新增仓储/执行器测试；独立项目边界检查、类型检查、单测与构建。

本批属于独立新项目的恢复底座，完整验证该新项目及真实多进程恢复，不改变旧核心流程或表语义，不运行旧项目 verify:full。测试数据均使用随机专用 wenmi_rebuild_test_* 数据库。
