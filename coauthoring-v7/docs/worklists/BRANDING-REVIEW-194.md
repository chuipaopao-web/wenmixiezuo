# R194 异模型审查与作品包装

实现与验证：modelId归一后跨套餐排除同模型，未知设计模型阻止独立审查；页面优先真实执行成员，预告从异模型主编中选择。两处取名按番茄表达，信息页移除其他平台选项。新增0120简介版本表和受书籍权限保护的GET/生成/保存接口，生成草案不覆盖已存、保存事务内版本比较、重启复用已有模型结果、部署计数纳入工作中简介。方向/开书/设定变动禁止基于过时规划生成。19项设计/取名集成、9项简介与信息页、1项开书真实仓储流程、共享引擎场景（含同模型不同套餐）通过；类型、共享运行时与API/作者构建通过。390/1440浏览器确认禁用、生成草案、保存与无横向溢出。模型均为模拟，未声称新简介真实模型质量通过。当前准备安全发布。

用户授权：单人开书设计必须由不同模型主编审查；首次开书与信息页取名参考番茄的直给卖点/反差表达；信息页增加作品简介，采用全书基线后可生成、编辑并保存。既有正文/内部大纲不作为对外简介覆盖。无可用异模型审查时明确阻断，不伪装独立；换员显示真实成员。简介使用当前已采用方向与开书必要信息，不注入全部设定，不泄露终局谜底、不虚构卖点、不照抄范例。生成草案与作者保存分开，作用域/幂等/版本冲突/费用沿用现有可信服务；失败保留原简介。新表追加兼容，测试后按在途安全窗口发布，不能取消作者任务。
