# R183：全书方向资料整理恢复

- 状态：开发中。
- 目标：修复管理员机甲书全书方向在资料整理阶段失败，使作者能继续生成实际方向后再讨论重构。
- 根因证据：原任务8次资料调用成功；末页反复超过18000字符，规则/facts/摘要与字段重复运输；重试未向资料阅读器传入恢复轮次。
- 范围：规划调用视图去除重复表示、空值；独有事实及条件、全局规则保留；冻结源不改。已完成调用幂等复用，失败页有限恢复。同步后台RB-22与路线、交接。
- 保留：作者开书、24项设定、原快照/版本、任务与计费审计、现有时光机交互、生成结果合同及模型配置。不实施新时光机设计，不自动生成或采用作者方向。
- 验证：针对重复字段、旧辅助条件、独有事实、全局约束、长资料分页与恢复、跨书/版本回归；实际冻结源只读重放及预算检查，必要合成模型探针；API构建与发布检查。
- 发布：后端兼容发布，静态资源保持R182，连续30秒零在途后切换API/Worker，健康/心跳/后台地图核查；失败回滚代码，不改生产作者数据。
