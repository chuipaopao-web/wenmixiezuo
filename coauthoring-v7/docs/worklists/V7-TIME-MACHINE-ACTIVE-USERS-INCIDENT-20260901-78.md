## 已冻结的最小修复

- 同一正式路线只接续最新框架任务；最新失败任务若是只读旧名册，则用当前正式路线、当前配方、当前资料快照和当前成员名册创建幂等替代任务。原任务、模型调用、成功检查点和审计记录保持不变。
- 重试前比较当前资料指纹、配方和路线；发生变化或旧快照缺失时创建新任务，不把旧任务先改成排队再失败；相同恢复请求复用同一替代任务。
- 小于等于8项的当前已确认设定，在总审失败或历史总账与当前确认项不匹配时使用轻量兼容总账；超过8项继续要求当前主编总审，防止上下文无界膨胀。
- 新路线创建时间晚于旧框架任务时，作者端只展示新路线并停止轮询旧框架；HTTP 4xx保留服务端真实处理办法，只有网络失败和5xx显示连接问题。
- 正文定稿进度与最近链解析分开返回；链读取失败只标记局部失败，已定稿章数和最新章不会消失。
- 任务日志只调整当前/历史投影，不删除任何历史行。旧失败仍可审计，但不能永久计入“正在进行或等您确认”。
