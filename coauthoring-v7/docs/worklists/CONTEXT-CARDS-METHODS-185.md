# R185：全书信息短卡与分层方法库

状态：开发中。最新授权为先完成这两项基础功能，再讨论时光机结果页。保持现有作者页面、账户、作品及历史任务；不实现节拍选择或新故事蓝图页面。

## 交付
1. 固定六栏全书设计短卡：创作要求、主角与起点、核心卖点、世界背景、影响全书的规则、作者指定内容。资料成员从当前已确认开书和设定中整理，不创作新剧情。分批读取、短卡合并、来源引用核验、预算检查、有限恢复，按owner/book/来源版本缓存；原文保留，不用字符截断替代整理。先接全书方向准备阶段，其他层不盲目继承此卡。
2. 后台资产方法论以时光机、卷、链、章分页呈现名称与简短介绍，共用定义、分层启用。原长理论从默认入口退出，历史方法引用保留兼容，不物理删除历史记录。方法预览与运行片段同源。精简重复，补充常用结构/推进/表现方法，说明嵌套承接责任。
3. 后台显示短卡模板和资料成员整理规则；功能管理、详细规格、开发路线同步真实实现。

## 验证与发布
验证资料跨书隔离、版本变化失效、未知引用、过长输出、失败恢复、缓存复用；方法跨层使用与预算、旧版本读取、编辑发布及移动端；真实模型合成书样本检查准确和精简程度，不冒充长篇质量。新迁移只增加投影表，可由原文重建。发布前完成构建、闭包、格式/模块检查；静态原子发布，API/Worker必须在途连续30秒为零，逐服务验证并保留代码回滚。不清理、停止作者任务制造窗口。若安全窗口不成立，仅暂存并如实报告。
