## 两轮设计审查

design_review_id：`DR-V7-OPENING-PREBOOK-USAGE-20260823-01`

### 第一轮：范围、权威来源与账号隔离

- 建书前没有合法 `book_id`，不创建半成品书，不把调用伪装成书内任务。
- 新表只以已验证账号的 `owner_id` 为权威范围，并以外键和所有查询条件双重隔离；跨账号读取测试返回 404。
- 只保存开书思路哈希、成员/模型身份、调用状态、真实用量、校验后结果和失败分类；不保存模型思维链。
- 页面继续复用既有 opening blueprint、分类目录、角色与背景字段，作者原始 `openingIdea` 单独保留，AI 回填不能覆盖作者原话。

结论：通过。

### 第二轮：计费、失败、幂等与恢复

- 首次请求先按最大调用上限做会员额度预留；相同账号、相同幂等键和相同开书思路只执行一次。
- 模型已成功返回时记录其真实输入/输出 token；即使页面结构校验失败，真实消耗也不被抹掉。可证明未执行的技术失败不写成成功用量；结果未知的中断保守保留预留，避免重复消费。
- 页面以真实 API 状态显示不定进度，不编造百分比；关闭/刷新后凭保存的设计编号继续查询。进程重启后长期未完成记录会转成可重试失败，不永久显示“正在设计”。
- 结构最多技术修复 1 次；最终结果仍须通过分类、标签、角色、时代背景、开局、故事方向和结局校验后才回填。

结论：通过。
