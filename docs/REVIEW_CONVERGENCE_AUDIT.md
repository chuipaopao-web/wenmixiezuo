# 三席审校独立性与收敛审计

- `design_review_id`：`DR-20260720-07`
- `release_id`：`wm-longform-r1-20260719-003435-e4d7b8b7`
- 触发时间：2026-07-20
- 适用 Skill：`wenmi-longform-quality`
- Skill SHA-256：`DFBB5275C6521CAF248DBFB89229ACEAA34ADA4AAEC279CE2A272E8D4D11BF07`
- 证据等级：E2，来自真实订阅/套餐模型的同章连续审校和改写；尚不声称E3/E4长期质量结论。

## 1. 事实、推断、偏好和未知项

已确认事实：第1章在两组正式任务中各完成两轮整章改写；最终轮均由事实席和体验席判定 `pass`，文学席单独判定 `rewrite`。文学席在不同轮次持续提出新的 `major` 风格目标，而不是只复验上一轮修改；活动主编已由Codex接管为Kimi，和文学席共享同一模型来源。旧合并代码只要任一席返回 `rewrite` 或任一问题标记为 `major` 就继续改写，达到两轮后直接 `QUALITY_BLOCKED`。

可验证推断：单一主观席可以不断移动目标；同源主编综合会放大该席判断，形成“自己批评、自己确认”的非独立循环。该循环会消耗Token、反复改写无问题段落并降低创造性，且不能在50章规模收敛。

老板明确偏好：三异模型点评保留，AI腔、政治和情色风险必须检查；产品要能长期生成正文，不能靠伪造通过或无限消耗。

未知项：新的收敛规则对不同题材和500万字纵向质量的长期影响仍需50章样本、跨题材盲评和后续E3/E4证据验证。

## 2. 痛点—根因—机制—反例—指标—停止条件

| 项目 | 内容 |
|---|---|
| 痛点 | 正文实际改善后仍被单席新风格目标反复阻断，流水线不能进入老板确认。 |
| 症状 | 两席通过、一席重写；每轮文学 `major` 数和位置变化；同源Kimi主编再次采纳Kimi文学席。 |
| 根因 | 合并层把单席主观严重度当成独立共识；两轮上限只有停止消耗，没有把剩余分歧交给老板。 |
| 机制 | 前两轮仍处理任一有证据的 `rewrite`；第三轮若仅文学或体验一席反对、另外两席通过，且没有事实重大项、blocker、中高合规风险或跨席硬问题，则保留异议并进入老板确认。 |
| 反例 | 不能用多数票覆盖正史矛盾、安全/政治/情色风险、事实席重大问题、任一blocker或两个独立职责同时发现的硬问题。 |
| 指标 | 单章最多两轮自动改写；报告、证据和少数异议全保留；主观单席不再形成无限循环；硬问题阻断率不下降；正文盲评不得劣于旧稿。 |
| 停止条件 | 若发现事实/合规问题被错误放行、跨席硬问题漏拦、或盲评显示人物声音/原创性/整体阅读质量下降，立即回滚收敛例外。 |

## 3. 替代方案

1. 维持现状：会稳定复现不收敛和同源自证，不采用。
2. 简单多数票：可能让两席忽略事实席的重大矛盾或安全问题，不采用。
3. 删除文学席或降低全部 `major`：破坏三席价值和AI腔检查，不采用。
4. 每轮增加新模型仲裁：增加费用、延迟与模型数量，仍可能产生新主观目标，不采用。
5. 采用有界分歧收敛：保留前两轮修改机会，第三轮只对“单个主观席、另两席通过、无硬风险”启用，最终仍由老板确认；采用。

## 4. 两轮审查

第一轮反例审查：如果“两个pass就通过”，事实席单独发现的时间线矛盾可能被体验和文学席漏检。修正为事实席重大项、事实席 `rewrite`、中等及以上合规风险和任一blocker永不使用收敛例外。

第二轮创造性审查：如果主编把所有文学异议都丢弃，会降低语言质量。修正为前两轮仍完整执行文学修改；第三轮只停止机械追逐移动目标，报告、位置、证据、动作和主编异议仍保存并展示给老板。模型来源重合必须写入主编输入，不能冒充第二份独立佐证。

结构一致性补充：真实事实席曾返回 `pass` 同时列出5个 `major`，主编又把可局部修复的问题综合为 `blocked`。前者必须在一次结构修复路径中保留 `major` 并把结论归一为 `rewrite`；后者不得由综合模型单独升级，阻断级别必须由三席原始证据或合规风险产生。

## 5. 验证与回滚

- 单元测试覆盖：首轮单文学重大项触发重写；第三轮单文学异议进入老板确认；事实重大项、blocker、中等合规风险和跨席硬问题仍重写或阻断。
- 集成验证覆盖：质量阻断任务释放租约后，作者可保存新不可变版本并再次定稿；未终态任务仍拒绝并发编辑。
- 50章真实模型验证保存每轮报告、综合、版本、哈希、Token和正史确认记录。
- 回滚只撤销裁决规则与提示词；不得删除已生成正文版本、点评报告、模型调用、正史或老板确认记录。
