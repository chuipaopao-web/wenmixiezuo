# 章节式正文导入与作者原文处理审查

## 明确结论与置信度

结论：正文页改为章节工作台。左侧始终显示第一章、第二章等章节目录，右侧只导入、阅读或修改当前章；表达优化、自然化、自定义优化和AI点评只能基于已保存的当前章版本运行。整本TXT识别继续保留，但降为显式打开的批量辅助入口，不再占据空书正文首页。

本设计对界面、版本保护与任务路由正确性的置信度为高，对真实模型改善文学质量的置信度为中低。当前只形成 E0—E2 工程证据，不能据此宣称“去AI味成功”或文学质量必然提高。

## 最强替代方案与取舍

1. 维持整本输入器。优点是一次粘贴方便，缺点是默认页面失去章节结构、长文本难核对，拒绝。
2. 新建独立导入和优化数据库。优点是可完全定制，缺点是复制正文权威、版本和任务状态，拒绝。
3. 章节工作台复用现有不可变正文链。常用入口清楚，原文可追溯，整本TXT仍作为按需批量能力，采纳。

## 预先验尸与反例

- 若空书同时在左右两处显示“添加第1章”，界面仍然重复；因此只保留左侧目录入口。
- 若作者修改文本后未保存就启动优化，模型会处理旧版本；因此存在未保存修改时必须禁用AI动作。
- 若“自然化”以检测分数为唯一目标，可能损害有意的整齐句式、人物口癖或情绪力度；因此它只能生成候选，作者决定是否采纳。
- 若点评按钮直接结算正史，会超越作者权限；因此复用的审校链仍必须停在作者确认之前。
- 若只允许逐章导入，已有百万字整书会难以迁入；因此保留折叠的整本TXT识别和恢复入口。

## 修正后的最终设计

- 页面默认左右分栏：左侧为章节目录、添加下一章和按需批量导入；右侧为当前章编辑器。
- 空书显示“第1章”占位；作者点击一次建立真实第1章，再粘贴当前章或选择单章TXT。
- 逐章保存使用现有作者草稿端点，产生新的不可变完整版本。
- “优化表达”改善清晰度、节奏、场景衔接和句式变化，但不得新增剧情或设定。
- “自然化（去AI腔）”减少模板化总结、空泛修辞、机械排比、重复解释和同质句式，但不得故意制造错误。
- “自定义优化”允许作者给当前章专属要求；三种优化都只生成候选版本。
- “AI点评”提交现有三异模型审校链；是否采纳、修改或定稿仍由作者确认。
- 整本TXT识别仅在作者显式打开或存在未完成批量导入时显示。

## 创造性与输出质量保护

- 自由创作区：作者原文始终保留，AI输出仅为候选；作者可不采纳、继续手改或使用自定义要求。
- 软硬边界：剧情事实、人物动机、人物声音与情绪强度是保护边界；表达建议、AI腔提示和点评分数都是软建议。
- 创造性非劣效基线：同一作者原文在旧通用重写流程下的候选，以及完全不使用AI的作者原文。
- 非劣效维度：原创性、合理惊喜、人物可辨识度、情绪力度、事实锚定和整体阅读质量；任一核心维度明显下降不能由“更像人”分数抵消。
- 盲评要求：E3阶段需隐藏版本标签，跨至少三种题材比较原文、表达优化、自然化与自定义优化；本次没有伪称已经完成真实盲评。

## 剩余风险与未知项

- 当前“AI点评”复用正式审校入口，名称更符合作者理解，但后台仍包含定稿前审校步骤；需继续避免文案暗示自动定稿。
- 自然化提示在不同模型上的稳定程度未知；必须通过真实样本非劣效评测后才能形成强质量结论。
- 很长的单章TXT当前设有十万字符保护上限，异常超长章需要拆分或走整本识别。
- 单书章数很高时目录分页、搜索和定位体验仍需真实千章数据验证。

## 停止、回滚和升级条件

- 需要新密钥、实际付费、生产数据恢复、永久删除、重大岗位/模型合同变化或修改 `D:\AI智囊团` 时停止并升级老板。
- 任一作者原文或历史正文版本被覆盖、未保存修改被错误提交、跨书章节错配、点评自动写入正史时立即停止。
- 任一真实样本中人物声音、情绪力度、原创性或整体阅读质量明显下降时停用对应优化预设。
- 回滚只撤销章节式界面和预设动作；作者原文、候选版本、任务、点评报告和正史不得删除。
