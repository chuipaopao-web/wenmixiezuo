# 设定资料库与逐项设计开发验收清单

> 生效需求：2026-08-21 老板最新决定。旧设定页布局、旧选择门禁和旧资料包行为与本文冲突时，以本文为准。

## 一、用户可见目标

- [x] 作者进入设定页时只看到收起的“完整设定库”入口，不再先看到旧版卡片矩阵和并列工作区。
- [x] 打开资料库后默认勾选核心设定与题材推荐设定；其他设定由作者自行勾选。
- [x] 资料库内全部可选类目必须可打开查看；未勾选即表示本轮不设计，作者勾选“已查看并确认本轮选择”后才可开始。
- [x] 点击开始设计后先出现确认提示，明确本轮条目数量、逐项设计和最后主编审查；作者确认后才创建任务。
- [x] 开始后资料库自动收起为一个按钮，页面只展开当前设定项；当前项确认后进入下一项。
- [x] 所选设定全部确认后，才显示并允许“主编审查”；主编不可用、任务失败或中断时保留结果并给出恢复动作。

## 二、页面与交互状态

- [x] 初始/加载：首屏唯一主操作为“查看完整设定库”，说明本步产出但不铺开全部解释。
- [x] 选择：核心与推荐默认勾选；其他设定可搜索、分组折叠和勾选；清楚显示已选择、待决定和总数。
- [x] 未确认资料库：开始按钮禁用；确认后显示本轮已选总数并允许进入二次确认。
- [x] 开始确认：使用可访问的确认对话框；取消不改变当前选择、不启动 AI。
- [x] AI 工作中：只展示当前项、真实成员状态、进度和可离开说明。
- [x] 待作者决定：支持整份选择、片段选择、编辑、重做、自写和留白；不提前调用主编。
- [x] 部分/全部失败：成功方案保留；只重试失败成员或继续未完成部分；刷新后状态可恢复。
- [x] 单项完成：收起当前过程并自动切换下一项；允许从设计清单查看已完成内容。
- [x] 全部完成：逐项设计区收起，只保留设定库按钮、完成摘要和“主编审查”主操作。
- [x] 修改：修改已确认条目创建新版本，不覆盖历史版本；重新进入后按最新活动内容工作。
- [x] 清空：仍使用影响提示、`YES` 和二次确认；不删除历史版本、正文或正式作者数据。

## 三、临时设定资料包与 AI 合同

- [x] 每次开始下一项、重新设计或失败成员恢复前，从当前 `owner_id + book_id` 的活动设定工作区重新编译临时资料包。
- [x] 临时包包含此前全部已确认条目的短摘要、稳定来源键和内容指纹；排除当前项、候选稿、失败草稿、其他书与其他用户数据。
- [x] 临时包明确标注“未经主编审查、不是正史”，只能约束本轮设定设计，不得写入正式设定基线或正文正史。
- [x] 作者修改已确认条目后，新编译资料包使用新版本摘要和新指纹；不得继续复用旧内容。
- [x] 作者清空全部设定后，新编译资料包为空；已存在的任务快照保留审计，但不能被新任务复用。
- [x] 摘要压缩有明确字符预算，不静默截断条目标签、来源或边界说明；无内容时明确为空。
- [x] 同一请求幂等，重复点击不重复创建任务；资料指纹变化后不得错误复用旧成功任务。
- [x] `design_review_id`：不适用。本次临时包是可删除重建的非权威投影，不改变正式 ContextCompiler 权威来源；正式基线仍只在主编审查和作者确认后生成。

## 四、数据、权限与失败兜底

- [x] 所有读取和任务创建继续携带已验证会话、`owner_id`、`book_id`；跨书资料为零。
- [x] 正式设定、正文、结算和版本历史不可被普通清空覆盖。
- [x] 模型不可用、单成员失败、任务中断、刷新恢复继续进入现有问题记录与任务恢复链路。
- [x] 不在页面、日志、资料包或测试夹具中泄漏密钥、模型思维链和内部路径。
- [x] 不为旧 UI 保留并行入口；只保留读取旧数据所需的最小兼容层。
