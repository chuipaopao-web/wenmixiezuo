# 文秘写作使用说明

## 启动与停止

双击桌面的“文秘写作”入口，等待浏览器打开。首次使用请在登录页用邮箱、昵称和至少10位密码注册；系统中的第一个账号会成为管理员。以后使用同一邮箱和密码登录。若桌面入口缺失，可双击项目根目录的“文秘写作-启动.cmd”。若启动窗口提示错误，不要重复点击，记录错误后再处理。停止时使用“文秘写作-停止”入口，只停止本项目登记的进程。

## 新建一本书

1. 在创作台左侧书籍栏点击“新建书籍”。
2. 填写书名、频道/分类、题材、初始角色、必须遵守和自己的补充想法。
3. 确认创建后进入设定。确认第一卷方案后，可在“信息”页点书名或书籍简介旁的“主编设计”，让主编依据第一卷故事、设定和开书信息设计多套书名或简介候选，选一套直接采用。
4. 进入设定后先点“完整设定库”。只有四项核心设定固定加入；题材推荐和其他类目都不会默认勾选，只把这本书确实需要的条目加入。
5. 勾选“我已确认勾选完毕”，再点“开始设计”。不会再出现二次确认页或弹窗；资料库立即收成一个按钮，页面只打开当前项。
6. 每一项选择一名或多名编剧出方案；成员旁显示“编剧”或“高级编剧”，高级编剧另标“高消耗”，不显示模型名。开始后状态显示“工作中、已完成、已失败”，单个成员失败不会丢掉其他方案，可只重试失败成员。每份方案可展开查看，也能让原编剧按最新资料重新设计并保留其他成功方案。
7. 方案默认折叠。展开后可整份选用或勾选片段，再点“交由主编融合”形成可编辑稿；作者可直接修改，修改后可点“按此整理”让主编只基于当前修改稿做专业化整理，最后确认。“我已有现成内容（参考建议）”“自己写一份”和“先留白，以后再定”均可展开、收起。已确认条目会压缩进非正史临时资料包，下一项读取最新摘要；修改或清空会同步更新临时包。
8. 页面会一直提示“全部设计完毕后，交由主编审核”。全部所选项完成后“请主编审查”才可用；逐条处理主编建议并确认后，设定形成正式稿，页面自动进入分卷。

## 规划当前卷

1. 填写卷目标、预计体量、卷末状态和自己的想法。
2. 选择大白话节奏参考，也可以不用或混合多个模板。
3. 比较 AI 候选，确认活动卷纲。
4. 生成事件链，检查每个事件为什么发生、解决什么、带来什么新状态。
5. 选中当前事件，生成并确认完整事件大纲。
6. 让系统评估章数和字数，再生成当前事件章纲。

## 写正文

1. 打开章纲，补充本章指导意见。
2. 点击开始撰写；一次只正式生成一章。
3. 查看事实、文学、体验三份独立报告。
4. 直接编辑或让写手按指定建议修订。
5. 满意后定稿，系统才会结算本章事实和状态。

## 事件和卷结束

事件全部章节定稿后查看事件结算，确认实际结果、人物变化、遗留问题和下一事件触发。当前卷完成后查看卷结算，再规划下一卷。规划内容不是正史，只有定稿正文及确认资料才记录已发生事实。

## 续写已有作品

1. 新建书时选择导入已有正文。
2. 核对章节识别和顺序后确认导入。
3. 原文保存为不可变版本，系统不会改写。
4. 查看带来源的反向拆解结果，确认或修改人物、设定、事件与当前状态。
5. 补齐当前卷、事件和章纲后继续写作。

## 资料库和取名

- 资料库统一查看人物、势力、地点、物品、规则、事件、关系、情绪、伏笔、信息差、来源、冲突与缺口。
- 取名按人物、地点、势力、物品、生灵和能力生成候选，不会自动写入设定。

## AI 成员状态

顶部“团队”显示全部15名创作成员。“准备中”表示正在编译本次资料；“工作中”表示真实模型调用已经发出；“完成”表示结果已保存；“失败/超时”会显示原因和可执行操作。小文秘书不计入人数，也不作为创作成员显示。

所有AI任务都在服务器后台执行：下达任务（开书、续写、设定讨论等）后即可关闭页面或退出登录，任务不会中断，重新打开后可在任务中心查看进度与结果。不同用户、不同书籍的任务同时并行执行，互不排队；同一本书内同时只执行一个任务，以保证设定与正文的一致性。章节生成到“审校检查点”时会暂停等待作者确认，这是功能设计而非中断，确认后继续。

## 书籍与创作导航

登录后可以切换当前书、创建或归档书籍，再进入当前书的创作阶段。当前版本仍可能使用左侧书籍区和顶部功能区，但后续会持续调整；请以页面显示的当前书名、当前对象状态和主操作为准。

手机端书籍和辅助功能可能收进抽屉或分段页面；桌面端可能提供更宽的对象导航和临时比较面板。无论布局如何变化，切换书籍不会改写数据，长书名保留原文，显示截断不影响正式书名。开发验收运行标识只转换为普通中文标签，内部标识不展示给作者。

## 数据边界

作者输入、附件、选择和反馈保存在所属对象中，不写入聊天记忆。其他书不会进入当前书上下文。摘要和向量只用于导航，事实争议会回查正式资料和定稿正文。

## 测试与备份说明

开发和自动测试可以使用确定性假模型验证流程、格式与恢复机制，但它不代表真实模型的文学质量，也不能冒充真实模型调用。当前Git历史与同一磁盘上的副本都不等于第二物理备份；重要书籍应另存到另一块物理磁盘后，才能声称具备该级别灾备。

## 查看已完成的规划

事件或整卷完成后，规划和章纲不会消失。进入“规划”可以查看已完成事件链、每个事件的大纲和版本；进入“章纲”可以查看该事件全部已确认、已冻结的章纲；一卷包含多个已完成事件时，可在页面顶部切换事件。历史页只供核对和复制，不显示重新生成、冻结、写作或结算按钮。若正文已经存在而这两页为空，应视为界面或工作流缺陷，不能按“正文数量足够”判定流程通过。

## 账号与管理员

本机使用也需要登录。退出后当前浏览器会话立即失效，但书籍仍保留在该账号下。作者创作台左栏底部显示当前昵称、身份和算力值余额，只提供“反馈”和“退出”，不显示平台管理入口。管理员单独访问 `https://admin.wenmixiezuo.com` 登录后台，可管理用户、算力、真实 API 成本、模型、失败任务与反馈、创作模板、提示词和会员经营数据；普通账号访问会被服务端拒绝。暂停账号后其已有会话立即失效。当前没有上线邮箱找回密码、手机号或微信登录，公开邀请其他人之前应先补齐这些运营能力。

## 会员与算力值

普通账号需要有效会员才能生成内容。当前档位为青铜（免费体验，20万算力值）、白银（2000万）、黄金（5000万）和钻石（2亿）；付费档周期为12个月，算力值按真实输入/输出用量换算，用完或到期后暂停新的AI生成，续费后恢复。管理员账号不限算力值。服务端会员门禁不能由前端绕过。管理员在独立 `https://admin.wenmixiezuo.com` 后台开通、续费或撤销会员，填写真实实收金额并查看到期时间、套餐分布、开通/续费流水、收入以及用户周期和累计消耗；历史没有正式流水的数据不会被反推为收入。
