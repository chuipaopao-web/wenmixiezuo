# 文秘写作使用说明

## 启动与停止

双击桌面的“文秘写作”入口，等待浏览器打开。首次使用请在登录页用邮箱、昵称和至少10位密码注册；系统中的第一个账号会成为管理员。以后使用同一邮箱和密码登录。若桌面入口缺失，可双击项目根目录的“文秘写作-启动.cmd”。若启动窗口提示错误，不要重复点击，记录错误后再处理。停止时使用“文秘写作-停止”入口，只停止本项目登记的进程。

## 新建一本书

1. 在创作台左侧书籍栏点击“新建书籍”。
2. 填写书名、频道/分类、题材与标签、初始角色、故事方向、必须遵守和自己的补充想法。
3. 确认创建后进入设定。
4. 在每个设定项查看主编与两位编剧的独立方案；选择、组合、直接改写或要求重做。
5. 所有当前必需设定确认后进入当前卷。

## 规划当前卷

1. 填写卷目标、预计体量、卷末状态和自己的想法。
2. 选择大白话节奏参考，也可以不用或混合多个模板。
3. 比较 AI 候选，确认活动卷纲。
4. 生成事件链，检查每个事件为什么发生、解决什么、带来什么新状态。
5. 选中当前事件，生成并确认完整事件大纲。
6. 让系统评估章数和字数，再生成当前事件章纲。

## 写正文

1. 打开章纲，补充本章指导意见。
2. 点击开始撰写；一次只正式生成一章。
3. 查看事实、文学、体验三份独立报告。
4. 直接编辑或让写手按指定建议修订。
5. 满意后定稿，系统才会结算本章事实和状态。

## 事件和卷结束

事件全部章节定稿后查看事件结算，确认实际结果、人物变化、遗留问题和下一事件触发。当前卷完成后查看卷结算，再规划下一卷。规划内容不是正史，只有定稿正文及确认资料才记录已发生事实。

## 续写已有作品

1. 新建书时选择导入已有正文。
2. 核对章节识别和顺序后确认导入。
3. 原文保存为不可变版本，系统不会改写。
4. 查看带来源的反向拆解结果，确认或修改人物、设定、事件与当前状态。
5. 补齐当前卷、事件和章纲后继续写作。

## 资料库和取名

- 资料库统一查看人物、势力、地点、物品、规则、事件、关系、情绪、伏笔、信息差、来源、冲突与缺口。
- 取名按人物、地点、势力、物品、生灵和能力生成候选，不会自动写入设定。

## AI 成员状态

顶部“团队”显示全部11名创作成员。“准备中”表示正在编译本次资料；“工作中”表示真实模型调用已经发出；“完成”表示结果已保存；“失败/超时”会显示原因和可执行操作。小文秘书不计入人数，也不作为第12名成员显示。

## 左侧书籍栏

书籍栏使用单列固定大竖版封面并在栏内向下滚动。在左侧书籍栏中，书名只显示在封面内，封面右侧不再重复；封面下只显示“当前书籍”“创作中”或测试标签。中心“信息”页会显示一次干净书名，便于确认当前开书资料。顶部功能栏上方不再重复当前书名或当前功能。桌面端功能栏没有额外的三横线按钮，12个功能入口等宽、等间距；窗口变窄且书籍栏收起时才出现打开书籍栏的按钮。新建和修改书名最多15字，字数越多封面字号越小，15字以内始终完整显示。开发验收书若带内部运行标识，界面会显示为中文“流程测试”或“验收测试”；原始标识只保留在数据库和测试证据中，普通作者书名不会被改写。旧数据若超过15字不会被系统擅自截断保存，封面用省略号兼容展示。

## 数据边界

作者输入、附件、选择和反馈保存在所属对象中，不写入聊天记忆。其他书不会进入当前书上下文。摘要和向量只用于导航，事实争议会回查正式资料和定稿正文。

## 测试与备份说明

开发和自动测试可以使用确定性假模型验证流程、格式与恢复机制，但它不代表真实模型的文学质量，也不能冒充真实模型调用。当前Git历史与同一磁盘上的副本都不等于第二物理备份；重要书籍应另存到另一块物理磁盘后，才能声称具备该级别灾备。

## 查看已完成的规划

事件或整卷完成后，规划和章纲不会消失。进入“规划”可以查看已完成事件链、每个事件的大纲和版本；进入“章纲”可以查看该事件全部已确认、已冻结的章纲；一卷包含多个已完成事件时，可在页面顶部切换事件。历史页只供核对和复制，不显示重新生成、冻结、写作或结算按钮。若正文已经存在而这两页为空，应视为界面或工作流缺陷，不能按“正文数量足够”判定流程通过。

## 当前项目文档合订版

桌面“文秘写作项目文档”首页顶部提供“一页看完当前项目”。打开后可在一个页面阅读并复制全部现行产品、流程、AI成员、上下文、检索、架构、数据、验收和Skill资料。项目根目录中的 docs/PROJECT_REFERENCE_BUNDLE.md 是同一内容的Markdown版本，适合整体复制给外部顾问。

## 账号与管理员

本机使用也需要登录。退出后当前浏览器会话立即失效，但书籍仍保留在该账号下。左栏底部显示当前昵称、身份和算力值余额；管理员点击“管理”可查看用户统计、搜索用户并暂停或恢复普通账号。暂停账号后其已有会话立即失效。当前没有上线邮箱找回密码、手机号或微信登录，公开邀请其他人之前应先补齐这些运营能力。

## 会员与算力值

普通账号需要管理员开通会员后才能生成内容。会员分三档：包月（10亿算力值）、包季（40亿算力值）、包年（200亿算力值），算力值即token，按周期内实际生成消耗扣减，用完或到期后生成会被暂停，续费后立即恢复。管理员账号不限算力值。开书填完资料跳转到设定页时，如尚无生效会员，会弹窗提示联系管理员办理（微信595341366）。管理员在“管理”页选择套餐即可开通或续费，也可撤销会员，并能查看每个账号的周期消耗与累计消耗。
