## 变更合同

### 用户目标

1. 设定条目设计中只显示一次执行状态，并显示实际接单成员的大头像。
2. 修复“按提醒优化”无结果、无可恢复任务的问题。
3. 作者修改设定并保存后，旧审查不得直接沿用；必须创建新任务并重新经过编剧整理、主编复审。

- 不改 V6 页面、V6 数据和 V6 工作流。

- 不处理本批次之外的导航、取名、封面和其他页面视觉重构。
- 不做生产部署；本批次完成本地构建与关键视口验收。

### 必须保留

- 单条重新设计仍支持选择 1 至 3 名编剧、分别出方案、选择或融合。
- 已确认设定保留版本历史；新任务只生成新候选，不覆盖已确认版本。
- `owner_id + book_id` 隔离、任务幂等、刷新后任务恢复。
- 设定结果折叠、设计思路折叠、主编提醒和补充设计能力。
