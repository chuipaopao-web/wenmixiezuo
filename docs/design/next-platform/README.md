## 视觉合同

- 画布：冷灰白；阅读面：暖白；唯一强调色：墨绿；危险态只使用克制红色。
- 字体：正文、控件、导航继续使用 `"SF Pro Display", "SF Pro Text", "Segoe UI Variable Text", "PingFang SC", "Microsoft YaHei UI", system-ui, sans-serif`；品牌字和页面大标题使用 `"Songti SC", STSong, "Noto Serif SC", SimSun, serif`。
- 桌面正文/控件 14–16px，辅助文字不低于 12px；手机可编辑控件不低于 16px；中文正文行高 1.65–1.8。
- 不使用巨型标题、渐变光斑、卡片墙、装饰性流程线、第三排导航或底部导航。
- 单屏只有一个视觉主操作。加载保持骨架，失败提供恢复，候选/确认/事实的来源与状态必须可辨。
- 原页面全部稳定几何区域相对旧版达到 95%；新增内容只允许出现在登记的既有板块内部。目录中的概念图只作为功能内容与状态语义参考，不再作为页面布局基准。

## 状态与来源语义

- 正文/结算事实：只读、可回溯到具体卷/事件/章节/版本。
- 作者规划：版本化保存，可停在任意阶段终点，不要求全书结局。
- AI 候选：显示成员、生成时间、证据和适用范围；作者确认前不进入硬事实。
- 开放问题：允许长期未知；不显示成缺陷、阻塞或红色待办。
- 失效候选：保留审计，清楚说明上游版本变化和重新编译入口。

## 响应式合同

- 桌面沿用旧版左书籍栏、顶部两排导航、原功能板块和原有内容顺序；只在原模块内部增加必要状态与操作。
- 手机在 360/390/430px 严格保留现有顶部两排导航；内容按当前决策顺序单列，不增加第三排或底部栏。
- 核心点击区不小于 44×44px；抽屉/对话框具备焦点锁定、Esc 关闭和可读标签。

## 图标清单
