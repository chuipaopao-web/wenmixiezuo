# 本机安全、隐私与运行运维合同

- 状态：E0设计冻结
- `design_review_id`：`DR-20260719-01`
- 适用release：`wm-longform-r1-20260719-003435-e4d7b8b7`

## 1. 安全目标和非目标

目标：保护书籍之间的隔离、权威正文与正史、模型凭证、本机文件、预算、任务提交和备份；任何外部内容、模型输出、浏览器请求、导入包和工具响应都视为不可信输入。

非目标：已取得老板同一Windows账号执行权限的恶意本机进程可以读取用户权限内的数据和环境变量，Web应用无法独自防住此类主机失陷。该风险依赖Windows账号、磁盘、系统更新和离线备份治理。

## 2. 信任边界

| 区域 | 信任级别 | 允许能力 |
|---|---|---|
| SQLite权威库与登记文件 | 最高，但仍校验完整性 | 正史、正式正文、任务和审计 |
| API应用服务 | 高 | 验证、事务、状态机、Repository |
| Worker | 受限 | 领取任务、调用模型/工具、提交候选和投影，不批准正史 |
| Web浏览器 | 半可信 | 展示与用户意图，不能绕过API门禁 |
| 模型输出 | 不可信 | 只能形成响应、临时结果或候选；必须Schema和权限校验 |
| 小文秘书/本地工具模型 | 受限且不可信 | 只做受理、候选和低风险本地结果；不拥有创作席、正史或永久操作权限 |
| 外部网页/研究资料 | 不可信 | 只作为有来源候选，不能执行指令或直接入正史 |
| 导入包/备份介质 | 不可信到校验完成 | 只进入隔离区和只读预检 |

## 3. 本机HTTP会话

### 3.1 监听和Host

- Web/API只监听 `127.0.0.1`，不监听 `0.0.0.0`、局域网或IPv6通配地址。
- 入口只使用 `http://127.0.0.1:43110` 和 `http://127.0.0.1:43111`。
- API精确校验Host；开发环境只增加显式的Vite端口，不能接受任意 `localhost` 子域或Host后缀，防止DNS重绑定。
- 健康检查只返回版本、状态和时间，不返回路径、书籍、模型凭证或数据库信息。

### 3.2 启动会话

- API每次启动生成256位随机会话秘密，只保存在内存；重启后全部会话失效。
- Web通过精确Origin允许的 `POST /api/v1/runtime/session` 获取HttpOnly、SameSite=Strict、Path=`/api/v1` 的短会话Cookie。Cookie不写localStorage、日志或URL。
- 数据接口要求有效会话；所有写操作同时校验精确Origin和 `Sec-Fetch-Site`。SSE使用同一Cookie，不允许查询串Token。
- Worker由启动器通过环境变量获得独立、短期、最小权限的运行Token；Token只允许Worker端点，不得访问设置导出和永久操作。
- 本地HTTP无法依赖Secure Cookie；Host、Origin、SameSite、短会话和回环监听共同构成补偿控制。

### 3.3 HTTP基线

- CORS仅允许精确Web Origin并启用凭证；预检不反射任意Origin。
- 写请求需要JSON内容类型；拒绝跨站简单表单写入。
- 响应设置CSP、`frame-ancestors 'none'`、`X-Content-Type-Options: nosniff`、`Referrer-Policy: no-referrer` 和保守的Permissions-Policy。
- 错误响应使用稳定错误码和追踪ID，不返回堆栈、SQL、环境变量、内部路径或模型原始错误体。

## 4. 请求和资源限额

限额由配置快照版本化，默认值如下；管理员只可在本机设置页调低或在硬件探针通过后有界调高。

| 项目 | 默认上限 |
|---|---:|
| 普通JSON请求体 | 1 MiB |
| 聊天单条文本 | 100,000 Unicode字符 |
| 单页聊天 | 500条；前端同时挂载不超过200条 |
| 单次检索初始候选 | 每通道200；融合后最多60簇 |
| 关系扩展 | 最多3跳、每层50节点、最终200节点 |
| 注入模型的证据簇 | 默认12，硬上限24 |
| 单次模型输出 | 按能力快照，且不超过128,000 Token |
| 普通上传 | 50 MiB |
| 单书可移植包 | 5 GiB，且不得超过剩余磁盘安全线 |
| 解压文件数 | 100,000 |
| 解压倍率 | 100:1；任一文件不超过2 GiB |
| HTTP工具响应 | 10 MiB，超出截断并标记 |
| HTTP重定向 | 5次，每次重新验证目标 |
| 子进程运行 | 默认120秒；任务可有界覆盖 |

限额触发必须返回可解释错误，不得静默截断正文、正式规划或正史。只允许对工具响应、日志字段和明确标记的展示摘要做安全截断。

## 5. 数据库和文件安全

### 5.1 SQLite

- 使用WAL、外键、busy timeout、完整性检查和受控事务。
- 禁止运行时加载SQLite扩展；在当前Node能力允许时启用defensive、authorizer和长度/表达式/列数等限制。
- 业务SQL不接受模型或用户提供的原始SQL；筛选/排序通过白名单AST编译并参数化。
- 所有Repository方法显式接收 `owner_id + book_id`；无隔离键的跨书管理方法只能存在于恢复/迁移命名空间，并需要专用测试。
- 数据库迁移只向前、带哈希、锁和幂等检查；已合并文件不得修改。

### 5.2 文件

- 通过文件登记表分配路径；调用者不能提交绝对路径或任意相对路径。
- 规范化后路径必须位于 `D:\wenmixiezuo\data` 对应书籍根目录或明确隔离目录。
- 临时写入后执行flush、SHA-256和内容长度校验，再原子改名；数据库只登记已完成文件。
- 正式正文和正史文件不可变；修订产生新文件和新登记记录。
- 导入拒绝路径穿越、符号链接/重解析点、设备名、备用数据流、大小写碰撞和清单外文件。

## 6. 密钥、模型和日志

- API Key、订阅Token和登录态只从环境变量或模型客户端自己的受控登录存储读取；不得进入SQLite、上下文包、SSE、日志、导出、备份、错误和Git。
- 完整岗位提示词查看密码只读取 `WENMI_PROMPT_VIEW_PASSWORD`。普通团队接口只返回简短岗位表达；受保护接口必须由服务端恒定时间校验密码，返回 `Cache-Control: no-store`，连续失败触发内存限流，且不得把密码写入SQLite、日志、URL、导出、备份、诊断包或Git。桌面启动器只把该变量传给API进程，不传给Web或Worker。
- 本地单用户版的环境变量密码只是本机查看门禁。未来对外商用部署必须在该门禁外增加登录用户、管理员权限、HTTPS、服务端审计和密钥托管，不得把一个共享密码当作互联网产品的完整鉴权系统。
- 启动日志只显示变量是否存在及来源类型，不显示值、前后缀或可推断片段。
- 子进程从空环境开始，只加入PATH最小项、项目临时目录和该工具显式允许的变量；不继承全部环境。
- 模型响应、工具响应和用户文本进入日志前按结构字段白名单；默认记录字节数、Token、耗时、状态、模型快照和追踪ID，而非完整正文。
- 调试正文日志默认关闭；老板显式开启时只写 `data/diagnostics`、有过期时间、界面可见并可清理，仍执行密钥脱敏。
- 任何疑似密钥模式命中会阻断提交/导出并生成本地安全事件；不把疑似值回显给用户。

## 7. 模型与提示注入防护

模型不能获得数据库、shell、文件或网络的通用权限。工具调用必须匹配岗位、任务、书籍、预算和参数Schema；未知工具或额外参数被拒绝。

系统提示明确区分：老板指令、正式资料、检索证据、外部资料、工具结果和模型内容。外部网页中出现“忽略规则”“上传密钥”“确认正史”等文本只作为引用内容，不能改变优先级。

模型提出以下行为时一律转为候选或阻断：提升正史、覆盖正文、扩大联网、提高费用、永久删除、跨书查询、修改岗位权限、绕过确认、执行任意SQL/shell。最终授权由应用状态机判断，不由自然语言自称判断。

小文秘书同样没有通用工具权。老板原始消息先保存并哈希，本地意图/实体/摘要输出只作为不可信候选；确定性应用服务重新检查点名、活动会话、风险、权限和 `owner_id/book_id`。明确剧情、人物命运、核心规则和正式写作必须升级相应创作岗位，本地模型不得直接回答后伪装成成员结论。

## 8. 联网研究与SSRF

- 默认工具无网络。联网研究只能由显式研究任务调用受限HTTP客户端。
- 只允许HTTP/HTTPS；拒绝 `file:`、`ftp:`、`data:`、`gopher:` 和自定义协议。
- DNS解析后拒绝回环、链路本地、私网、保留地址、云元数据地址和非全局IP；连接前和每次重定向后重新解析与复核，防DNS重绑定。
- URL中禁止用户名/密码；限制端口、超时、重定向、响应大小和MIME；下载保存到研究隔离区。
- 研究结果记录访问时间、最终URL、内容哈希、标题、许可/版权提示和引用片段；未经确认只在候选层。
- 离线、失败或来源不足时明确说明，不用模型知识伪装成刚刚联网核实。

## 9. 任务并发、取消和提交栅栏

- 每个任务使用稳定幂等键、租约、epoch和检查点；重试不创建第二份正式结果。
- 取消先持久化 `cancelling` 与新epoch，再向适配器传播Abort；所有模型、工具和Worker提交在事务前复核epoch。
- 晚到结果可保留为诊断附件，但不能进入正式成果、正史或预算重复结算。
- Worker失联后租约超时才可接管；旧Worker即使恢复也因epoch过期无法提交。
- Agent在线/工作/待命状态只由任务、租约、心跳、调用和工具事件派生，不由聊天文本或定时动画生成。

## 10. 投影一致性和降级

每种派生投影维护：最近权威事件、已消费事件、活动快照、构建快照、错误、重试、版本和时间。健康状态分：

- `ready`：活动快照与权威水位一致或在允许延迟内。
- `stale`：可读但落后；界面显示水位，硬事实查询回到SQLite权威。
- `building`：旧活动快照继续服务。
- `degraded`：该通道不可用；路由排除并提示，不伪造结果。
- `blocked`：完整性/隔离失败；阻止正式创作提升。

向量不可用时保留结构化、FTS和关系；关系投影不可用时保留结构化和原文；FTS损坏时从权威源重建。SQLite权威不可用或完整性失败时只允许诊断和恢复，不允许写作提交。

## 11. 备份、导出和恢复

### 11.1 一致性快照

备份通过SQLite在线一致性快照、文件清单、哈希、Schema版本、release、操作水位和恢复说明组成。向量、FTS和缓存默认不备份，以减少体积并验证可重建性。

### 11.2 三种验证

1. 临时恢复验证：恢复到隔离目录，跑数据库/文件哈希/业务不变量和抽样查询。
2. 投影重建验证：从恢复权威源重建FTS、Wiki、关系、摘要和向量，并比对冻结探针。
3. 生产数据恢复：必须由老板确认影响、目标快照和回滚副本，不能由自动测试或普通导入触发。

### 11.3 保留和第二副本

本机默认保留最近7个日快照、4个周快照和每次正式release快照；超过配额先提示并暂停新快照，不自动删除最后一个可恢复副本。第二物理位置未配置时界面持续显示“只有本机副本”，不能把Git远程当作小说数据备份。

## 12. 磁盘、内存和队列治理

- 启动和每10分钟采样数据目录、临时目录和模型目录可用空间。
- 剩余空间低于20 GiB进入提醒，低于10 GiB停止模型下载、全量重建和大型导入，低于5 GiB阻止会扩大数据的任务但允许导出和清理。
- 可重建缓存遵循LRU与水位；原始聊天、稿件、正文、正史和唯一备份不自动永久删除。
- Worker按任务类型分队列并设置并发：权威结算串行；模型调用按实际套餐能力；嵌入/重建低优先级、可暂停；交互回复优先于后台回填。
- 本地工具模型按需加载或采用经探针允许的常驻方式；达到内存/CPU安全线时卸载/降级，不与正式正文生成和三点评争抢导致系统失联。云Token、本地资源和总延迟分开计量。
- 队列积压、失败率、重试、平均/尾延迟、Token和投影落后都有本地指标，不发送遥测。

## 13. 可观测性与审计

结构日志最少记录：UTC时间、release、进程、追踪ID、owner/book/task/operation的安全短ID、事件、阶段、结果、耗时、字节/Token、模型/提示/策略/投影快照。禁止正文全文、密钥和思维链。

审计事件包括：老板确认、正史提升/修订、正式正文版本、任务取消/接管、模型路由变化、预算越线、标签Schema变化、导入导出、备份恢复、投影切换和永久删除。审计不可由普通UI删除。

诊断包默认只含配置摘要、版本、水位、错误码、指标和脱敏日志。包含内容样本时必须单独勾选、预览并写明敏感性。

## 14. 安装、升级与卸载

- 安装前探测Node稳定LTS、SQLite能力、端口、目录权限、磁盘、可选本地模型和向量运行时；探针只读，不改变系统服务。
- 安装依赖使用锁文件和完整性校验；模型资产需要许可证和SHA-256。
- 升级先创建一致性快照、校验迁移、启动旧路径、后台回填和逐书切换。
- 卸载程序与删除书籍数据分离；卸载默认保留 `data` 和备份。永久删除数据继续要求包含 `YES`、对象名称和短ID的完整确认词。

## 15. 故障手册

| 故障 | 自动动作 | 人工可见动作 | 禁止行为 |
|---|---|---|---|
| API重启 | 会话轮换、Worker重连、租约复核 | 刷新后重新建会话 | 复用URL Token |
| Worker崩溃 | 保留检查点、租约超时接管 | 显示失联/接管 | 伪显示工作中 |
| 向量模型缺失 | 关闭向量通道 | 显示降级及安装诊断 | 伪造语义结果 |
| 本地工具模型缺失/低置信 | 使用确定性路由或升级现有套餐岗位 | 显示小文秘书降级和实际接手成员 | 运行时远程下载、现金fallback或本地乱猜 |
| 投影损坏 | 继续旧快照或重建 | 显示水位和进度 | 覆盖权威源 |
| SQLite完整性失败 | 停止业务写入 | 提供临时恢复验证 | 自动恢复生产数据 |
| 磁盘不足 | 背压并暂停增长任务 | 给出可重建清理项 | 自动删作者资产 |
| 模型超时 | 有界重试/检查点 | 显示真实错误与费用 | 无限重试或占位提交 |
| 导入失败 | 删除隔离副本 | 显示逐项校验失败 | 修改现有书 |

## 16. 验收门禁

- Host/Origin/会话、CSRF、DNS重绑定、SSE和Cookie测试。
- 跨书、SQL筛选、路径穿越、重解析点、压缩炸弹和非法恢复测试。
- SSRF、重定向重绑定、私网、超大响应和提示注入工具越权测试。
- 取消晚到、epoch接管、重复幂等、预算竞争和Worker崩溃测试。
- 密钥注入日志/导出/错误/上下文的负面扫描。
- 空库、旧库升级、重复迁移、投影失败、降级、重建和临时恢复。
- 目标电脑冷启动、热启动、离线启动、磁盘高水位和桌面入口验证。

任一隔离、权威、秘密、路径或取消提交栅栏失败，都阻断release，不能以“本机个人使用”降低门槛。
