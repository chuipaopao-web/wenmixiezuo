# 当前账号安全、隐私与运行运维合同

## 1. 保护目标

保护书籍隔离、作者原件、正式正文、正史、活动规划、模型凭证、本机文件、预算、任务提交、正式化事件和备份。浏览器输入、附件、模型输出和工具响应全部视为不可信输入。

安全机制只保护数据和运行边界，不替作者决定剧情，也不把软创作建议升级为硬门禁。

## 2. 网络与部署边界

- API回环端口、Worker、SQLite、文件和内部健康信息不直接暴露公网；
- 本机测试时API与Web开发服务使用回环地址；公网时由同机HTTPS反向代理分别接收作者主站 `wenmixiezuo.com` 与管理子域 `admin.wenmixiezuo.com`，两者各自同源转发API到回环端口；
- Host只接受API监听地址和配置的Web域名，Origin只接受当前Web Origin，写请求校验 `Sec-Fetch-Site` 与JSON内容类型；
- CORS只允许配置的Web Origin并携带凭证；当前产品不开放旧SSE接口；
- 反向代理负责TLS证书、HTTP到HTTPS跳转、请求大小和访问日志；公网部署时注册、登录与全局请求限流由应用层 `@fastify/rate-limit` 在API内执行；
- 不开放SQLite、Worker或开发服务器端口，不以端口映射代替正式部署；
- 联网研究继续经过域名、协议、地址、跳转、大小和内容类型限制。
- 完整公网部署步骤、Caddy 配置、systemd 服务单元、备份脚本和运维命令见 [DEPLOY.md](DEPLOY.md)。

## 3. 账号、密码与HTTP会话

本机和公网使用同一账号体系，不存在固定本机用户或自动取得数据权限的页面会话。首发采用邮箱加密码：邮箱规范化后唯一；密码长度10至128字符，使用每账号独立随机盐和scrypt摘要，不保存或记录明文。首个注册账号在 `BEGIN IMMEDIATE` 事务中成为管理员；若历史本机老板所有者尚未被账号认领且包含书籍，该管理员在同一事务中复用它。后续账号为普通用户并创建全新所有者。升级迁移只允许在“唯一管理员、当前所有者无书、历史所有者存在且未认领”的条件下切换关联，不复制、不删除创作数据。

登录成功生成高熵随机令牌，浏览器只通过 HttpOnly、SameSite=Lax、Path=/ Cookie持有明文；服务端 `auth_sessions` 只保存SHA-256摘要、到期、最近活动和撤销时间。公网HTTPS启用Secure；退出、账号暂停和到期立即使会话失效。API重启不应让有效会话无故失效。

除 `/health`、注册和登录外，所有作者API必须验证会话；Worker内部端点使用独立且恒定时间比较的Worker令牌。所有业务范围从会话取得 `user_id + owner_id + role`，不能信任客户端提交的owner。管理员只能进入专用管理路由；普通业务路由即使管理员访问，也仍只读取管理员自己owner下的书籍。

## 3a. 会员与算力值门禁

普通账号注册时自动获得长期有效的青铜体验（20万算力值）；付费档为白银2000万、黄金5000万、钻石2亿算力值，当前周期12个月。算力值=真实token×2；`usage_ledger`与预算保存真实token，作者界面只显示算力值。当前V7在开书、规划、正文、人物、设定、书名和封面各自真正发起模型调用前统一调用会员门禁；会员缺失、到期或算力耗尽分别返回可恢复的403，恢复与重试不能绕过门禁。开书确认本身不触发AI任务，建书后由作者主动开始设定协作。管理员和未关联账号的本机遗留/测试owner不受会员门禁；会员开通、续费和撤销只限管理员，每账号至多一条活动记录，升级后书籍预算按配额的一半真实token同步刷新。

公开邀请用户前必须补齐并验收：邮箱验证、找回密码、注册/登录限流与异常告警、用户协议与隐私政策、账号注销和数据导出、HTTPS反向代理、备份恢复、管理员账号预创建。手机号和微信需要真实供应商/开放平台凭证与回调域名，后续绑定到同一 `user_id`，不能创建第二套账号数据。
## 4. 输入与输出限制

| 对象 | 当前限制原则 |
|---|---|
| 作者单字段输入 | 按字段Schema和Unicode字符数限制；保留原话，拒绝控制字符和异常超长输入 |
| 作者附件 | 白名单类型、大小上限、哈希、独立保存名、解析状态和绑定对象 |
| 查询与筛选 | 参数化SQL、枚举白名单、分页上限、书籍隔离键 |
| 模型输出 | Schema校验、长度限制、来源检查和候选状态；不能直接执行代码或SQL |
| 日志字段 | 脱敏、截断、路径归一和密钥扫描 |

前端显示模型文本时使用React文本转义；需要Markdown时只允许安全子集，不允许任意HTML、脚本、事件属性或危险URL。

## 5. 书籍与版本隔离

所有核心记录携带 `owner_id` 和 `book_id`。Repository方法必须显式接收隔离范围；跨书查询、任务、附件绑定和正文读取均测试错误书籍ID零命中。

活动开书、设定、卷纲、事件和章纲版本通过明确指针引用。任务冻结上游版本、正史水位和主编epoch；上游改变、主编切换或任务取消后，迟到结果只能进入隔离记录，不能覆盖当前候选或正式数据。

## 6. 模型凭证与隐私

- API Key只从环境变量读取；
- Key不得写入SQLite、配置文件、Git、日志、任务、ContextPack、模型请求快照、导出或备份；
- 错误信息只显示供应商、模型、状态码、请求ID和可执行处理，不显示认证头；
- 模型调用只发送当前任务编译后的当前书籍信息；其他书、无关正文和未授权附件不得进入请求；
- 调用记录保存模型绑定、预算、Token、耗时、来源指纹、结果状态和安全摘要，不保存思维链；

## 7. 作者原件、附件与正文

作者附件和导入原件使用独立不可变文件保存，SQLite记录哈希、大小、类型、创建时间、绑定对象和解析状态。展示文件名与物理保存名分离，禁止路径穿越、绝对路径注入、符号链接逃逸和脚本执行。

正文使用不可变完整版本。任何编辑、AI修订或作者接管都创建新版本；定稿与结算在事务中引用明确正文版本。正式正文文件写入采用临时文件、刷新、原子改名和哈希校验，禁止静默覆盖。

普通删除为归档。书籍永久删除只允许已归档书，必须先显示影响预览；用户输入 `YES` 并再次确认后，服务端重新校验归档状态，在事务和文件清理协调下删除全书数据并写墓碑。

## 8. Agent、工具与权限

岗位、Agent实例和模型绑定分离。创作成员只获得当前任务ContextPack和允许提交的候选类型，不能自由访问数据库、文件系统、网络、密钥或其他书。

小文秘书是确定性本地工具角色，只处理导航、附件、任务状态、格式检查和故障回执，不给剧情结论、不冒充模型，也没有通用Shell、SQL或联网权限。

模型提出以下行为时只能形成候选或被阻断：提升正史、覆盖正文、扩大联网、增加费用、永久删除、跨书读取、修改权限、绕过作者确认、执行任意SQL或命令。最终授权由应用状态机判定，不由自然语言自称判定。

## 9. 联网研究与版权来源

联网只允许 `http/https`，拒绝环回、私网、链路本地、文件协议、非标准重定向和解析后地址变化。每次跳转重新校验，限制响应大小、超时、内容类型和并发。下载内容进入来源区，不自动成为设定、正史或正文事实。

研究记录保存URL、标题、抓取时间、来源类型、短摘录、主张、许可备注和用途。大段版权原文不得进入主笔ContextPack；系统使用主张、结构卡和必要短摘录，并与创作索引物理隔离。

## 10. Worker、正式化与恢复

Worker当前只维护心跳，并可追赶`v7_formalization_outbox`。作者定稿、结算与outbox按当前事务合同绑定精确版本；消费者按正式来源幂等，失败可从SQLite检查点追赶，衍生维护失败不得回滚或覆盖正式正文。

- Worker只消费当前V7正式化事件，不运行旧任务领取、旧创作执行器或旧投影循环；
- 预算、权限、版本错配和作者确认缺失不自动重试；
- 迟到或重复结果必须由版本绑定和幂等键拦截；
- `unknown`状态停止盲目重发，等待可审计的恢复动作；
- 成员状态只由真实任务、心跳、模型调用和工具事件派生，不用动画伪造工作。

## 12. 日志与可观测性

结构化日志允许：时间、组件、任务、书籍匿名标识、请求ID、模型、状态、耗时、Token、预算、错误类别、检索通道、水位和恢复动作。

日志禁止：API Key、Cookie、认证头、正文全文、附件正文、作者敏感原话、完整ContextPack、任意本机私密路径和模型思维链。错误堆栈在对外显示前移除密钥、查询参数、用户内容和非项目路径。

## 13. 备份与恢复

一致性备份至少包含SQLite在线备份、不可变原件/正文、必要配置清单、活动版本指针和文件哈希。

同一磁盘上的复制和Git历史不等于第二物理备份。重要书籍需要写入另一块物理磁盘并完成恢复演练。恢复顺序为：校验清单与哈希 → 恢复权威数据 → 校验书籍隔离和活动版本 → 运行V7探针 → 开放写入。

## 14. 桌面启动与停止

桌面启动器只启动本项目登记的API、Worker和Web进程，先执行迁移，再通过不创建账号会话的轻量 `/health` 探针确认数据库与Worker就绪，最后打开登录页。全库完整性检查属于迁移、备份和正式验收，不放入高频启动轮询。模型套餐地址必须通过严格路径校验；错误时停止启动并显示可处理原因。

模型套餐只读取文秘写作专用的 `WENMI_ARK_CODING_PLAN_*`、`WENMI_ARK_AGENT_PLAN_*` 和可选 `WENMI_ARK_IMAGE_*` 变量。旧 Anthropic、AgentPlan 兼容别名不再进入运行环境，不得将其静默映射到当前套餐。所有模型凭证只传给 API 进程，从 Web 与 Worker 环境移除。

停止入口只消费由本项目生成并校验的停止请求和进程登记，不枚举或终止其他应用。启动、停止、重复启动、异常退出和端口占用都要有明确回执。

## 15. 必测项

- Host、Origin、Cookie、CSRF、DNS重绑定和回环监听；
- 跨书读取、写入、任务和附件零串线；
- 路径穿越、恶意文件名、异常编码、超长输入和危险Markdown；
- 密钥、正文、附件、ContextPack和本机路径不进入日志；
- 正式化幂等、迟到结果、版本绑定、预算和失败追赶；
- 空库迁移、已有库顺序升级、重复迁移和失败恢复；
- 不可变正文、定稿结算和书籍永久删除双确认；
- 启动、停止、重复启动、端口冲突与桌面入口；
- 备份哈希、第二物理介质和完整恢复演练。
