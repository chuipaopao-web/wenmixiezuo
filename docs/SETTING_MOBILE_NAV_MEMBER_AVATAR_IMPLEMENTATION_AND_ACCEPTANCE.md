# 设定页去重、成员头像与手机导航：开发及验收清单

更新时间：2026-08-22

## 一、先回答三个界面问题

1. 用户此刻要完成什么：在设定页快速查看本轮范围、选择实际参与成员并看清工作状态；在手机上能随时切换书籍和打开个人资料。
2. 当前最妨碍完成的是什么：设定库标题和说明重复、上下两处成员信息重复、选择卡堆叠职位与模型名；手机抽屉被写死为144px，个人资料只有30px头像可点。
3. 改完后首屏唯一主操作是什么：未开始时是“查看完整设定库/开始设计”，逐项设计时是“选择成员并请求方案”，其他说明和成员信息不与主操作竞争。

## 二、开发清单

### A. 设定库标题与说明去重

- [x] “设定骨架—勾选所需条目，请勿乱选”只显示一次，放在“完整设定库”后方并保持同一行优先。
- [x] 删除触发器下方的介绍文案、展开后的重复大标题和右侧范围说明。
- [x] 进入逐项设计后，完整设定库保持紧凑按钮，不重复展示流程说明。

### B. 手机书籍与个人资料

- [x] 手机书籍抽屉从144px改为适合360/390/430px的宽抽屉，遮罩永远位于抽屉下方。
- [x] 手机书籍列表显示清楚的书名和状态，长书名不纵向挤成难读多行；选择后自动关闭抽屉。
- [x] 个人资料入口改为整行可点、触控高度不少于44px，并保留明确的“个人资料”语义。
- [x] 抽屉内容可滚动，书籍和个人资料都不会被浏览器底栏或安全区遮挡。

### C. AI成员头像与状态

- [x] 删除设定页顶部整组成员展示，只保留当前任务附近的成员选择/工作状态。
- [x] 设定成员选择、运行状态、方案来源全部使用真实岗位头像，不再使用A/B/C/高等字母圆标。
- [x] 成员卡只显示头像、成员名和工作状态；不显示模型名，不重复“编剧/高级编剧”等职位文字。
- [x] 作者端其他显示AI成员身份的位置同步使用头像；平台后台的模型审计字段不在本次删除范围。
- [x] 等待、工作中、完成、失败、不可用均有文字状态，不能只靠颜色。

### D. 紧凑排版与文案清理

- [x] 成员方块内部优先单行排版，手机端不因说明文案膨胀成多行大卡片。
- [x] 逐项进度、成员工作进度只保留当前项、完成数和必要恢复动作，删除重复解释。
- [x] 失败原因和重试入口保留；营销式、模型式和内部流程说明删除。
- [x] 360/390/430px无横向溢出，所有关键按钮和输入仍可达。

## 四、边界

- 本次不改设定业务数据、模型绑定、任务派发、资料包或数据库；只调整作者端信息层级、成员展示和手机可达性。
- 用户账号、书籍隔离、历史内容、正式正文和API Key均不受影响。
