# 已有正文逐章分析与续写基线审查

- `design_review_id`：`DR-20260804-existing-manuscript-analysis-v1`
- 活动 `release_id`：`wm-longform-r1-20260719-003435-e4d7b8b7`
- 适用 Skill：`wenmi-longform-quality`
- 目标：让已有数万至数百万字正文的作者先导入和结算真实前文，再由系统逐章提炼可回查的续写资料；不得要求作者先按空白新书流程重做设定大纲。

## 事实基线

- 现有导入流程已经能确定性识别章节，并把作者确认的原文保存为不可变正文和前文正史。
- 现有导入结算只记录 `summaryStatus=not_generated`，没有逐章摘要、人物当前状态、事件、规则、开放线索和续写基线。
- 对话入口在识别已有正文之前先启动空白新书的设定引导，导致作者已有几万字正文仍被要求从头规划设定。

## 新合同

1. 原文先确定性分章并由作者确认；原文是唯一事实权威，任何分析都不得覆盖原文。
2. 确认后建立独立、可恢复的“已有正文分析”任务，由设定与连续性岗位逐章提炼：章节摘要、出场人物及章末状态、事件、地点、关系、规则、资源变化、开放/已回收线索、叙事和语言样本、章节结尾接口、冲突和未知项。
3. 逐章结果是带来源指针和模型快照的可重建派生资料，不自动成为新的正史事实。
4. 系统从逐章结果确定性汇总“续写基线”：前文简要脉络、人物当前状态、必须遵守的规则、未解线索、最近结尾、风格证据和待作者确认的真实缺口。
5. 对话入口只要发现已确认正文，就优先显示分析进度或续写基线；分析完成前不得启动空白新书设定流程，完成后只询问原文没有回答且会影响续写的关键问题。
6. 原文全文仅用于保存、逐章分析和精确回查，不整本注入模型。单次逐章分析采用有界切片；续写资料包继续遵守最小必要上下文。

## 两轮审查

### 第一轮：一致性、恢复与来源

- 分章确认和逐章分析分离，分析失败不回滚已确认原文。
- 每章以源哈希幂等；重试复用已完成结果，只继续失败或缺失章节。
- 跨书读取必须携带 `owner_id`、`book_id` 和导入批次。
- 摘要与结构化提取均保留原文章节和正文版本指针。

### 第二轮：创造性与注意力

- 续写基线用于防漂移，不把所有历史细节变成硬约束。
- “未知”必须保持未知，不因填满模板而编造设定。
- 风格只保存可引用的原文证据，不把统计模式机械变成每章固定写法。
- 主编先依据真实前文给出简洁诊断和候选方向；只有重大未来走向才启动双编剧，不让作者重复复述已有正文。

## 验收与回滚

- 验收：导入后可见逐章分析进度；分析完成后进入对话不会再出现空白新书的设定大纲门禁；续写基线可回查到原文章节；分析失败可重试且不复制章节。
- 回滚：停用分析任务与续写优先路由，保留新增派生表和历史分析记录；不得删除或修改已导入正文、正史、模型调用和任务证据。
