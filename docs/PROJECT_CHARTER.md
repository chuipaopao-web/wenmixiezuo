# 项目总章程

## 产品使命

把老板的创意、剧情梗概和方向要求，转化为可追溯、可修改、可持续300至500万字、1000章以上的小说创作成果。平台负责主动提问、组织讨论、形成方案、生成大纲和正文、三异模型点评、修订、结算正史、维护长期记忆，并让每书十一名稳定创作成员从开书到完结保持有依据的工作连续性；另由本地工具角色“小文秘书”承担低风险受理、资料准备和透明分流，需要老板决定时提供清楚的选择单。

## 产品边界

- 小说平台是独立产品，不是AI智囊团的功能页面。
- 当前仅供老板个人、本机使用。
- 首版不实现登录、多用户、租户、收费、商用后台、云部署、高并发、分布式系统或原生手机App。
- 当前不实现无限无人监督运行，也不执行未经确认的外部发布。
- 核心领域从第一天预留未来商用需要的归属、版本、审计和导入导出边界。

## 设计原则

1. 老板只负责表达想法、选择方向和体验成果，不要求老板读代码或处理技术问题。
2. 自然语言是主要入口，平台负责把模糊想法变成结构化创作流程。
3. 正文和正史是不可静默覆盖的资产；聊天不是长期事实源。
4. 所有Agent使用本地长期记忆和可追溯上下文包，不依赖单次模型上下文记住全书。
5. 讨论要有主持、范围、预算、共识和退出条件，不能无限调用模型。
6. 模型、岗位和Agent实例分离；真实能力和真实状态优先于人设描述。
7. 先保证数据隔离、版本、恢复和正史安全，再接入长任务和正文生成。
8. 低风险可逆工作尽量自动完成；重大正史、高费用、版权风险和永久删除必须严格确认。
9. 所有阶段以可验证结果为终点，不以“模型说完成了”为完成。
10. 模型上下文大小与全书总字数解耦；长期陪伴依赖正史、层级知识、滚动规划和岗位连续性记录，不依赖加载全部聊天或让所有模型全天运行。
11. 已结束阶段默认以阶段结算进入活动工作集；关键信息出现时逐级回查前文正史，既不按固定章数遗忘硬事实，也不把全部旧正文重新注入模型。
12. 前台工具角色不能成为隐藏主编；点名成员直达，剧情讨论由主编和双异模型编剧直接参与，老板原话不得被有损摘要替代。

## 不可突破的门禁

- AI智囊团停止后，小说平台仍能独立工作；反之亦然。
- Worker不能直接写正式正文和核心业务表。
- 前一章未结算，后一章不能进入正文生成。
- 重大正史变化必须由老板确认。
- 结果不明的模型调用不得自动重试。
- 跨书数据不得进入另一书的上下文、检索、任务或预算。
- 换名仿写、近似改写、翻译规避和标志性事件链照搬必须阻断。
- 永久删除只对已归档书开放；界面显示影响后，输入 `YES` 并再次点击“彻底删除”，服务端校验归档状态、原子清理全书数据并写删除墓碑。

## 首版成功定义

在本机完成两本测试书的严格隔离，并让主测试书逐章完成5章、每章2500至3500字。历史首版每章经过异模型审校；当前长篇release每个完整稿固定经过事实/文学/体验三职责、三异模型点评，GLM写手时事实席改用DeepSeek，再经主编合并、最多两轮定点重写、事实提取和正史结算。中断恢复、主编/副编与主笔/副笔接管、预算冻结、版权门禁、备份恢复和PWA核心体验全部通过。

上述首版成功定义只证明短流程发布，不代表最终超长篇目标完成。最终规模目标另按500万规范化中文字符、1500章的容量与连续性评测，以及真实模型纵向创作证据分级验收；不得从5章、200章或100万字符直接外推。

## 长篇终局增量边界

DEC-020以新release开发长篇终局能力，DEC-021补充十一人团队，DEC-025/026曾冻结最小开书、自然讨论、双编剧跨度评估、模型可配置和三职责独立点评，DEC-027冻结小文秘书、本地分层处理和透明路由；DEC-046进一步以完整开书资料、版本化番茄式分类和主编主动开场替代最小开书规则。历史首版证据保持不可变。新能力必须采用单一SQLite权威、向前迁移、可重建投影、逐书影子验证和可回滚策略指针；不得为500万字符目标直接引入微服务、独立向量/图数据库、云运行依赖或未授权费用。

容量、检索正确性、运行可靠性、创造性非劣效和真实纵向文学质量分别按E0至E4验收。完整设计和施工合同见 `docs/PRE_DEVELOPMENT_DESIGN_FREEZE.md` 与 `docs/superpowers/plans/2026-07-19-final-longform-platform-implementation.md`。老板已于2026-07-19明确开工，长篇终局release现按八阶段连续实施；真实模型凭证缺失时只取得允许的工程证据，绝不伪造E4文学质量。

## 卷驱动 V2 产品增量

DEC-107将作者主流程冻结为开书、设定、当前卷纲、事件链、当前事件章纲、逐章正文、事件/卷结算和下一卷。系统帮助作者在大方向下设计小事件，但规划不冒充正史，也不把局部创作自由压成机械执行。

成功不仅要求流程可运行，还要求每个AI任务引用正确的活动规划版本、最小充分正式资料和作者原话；卷末以实际正文结算，下一卷承接真实后果。页面精简不能损害附件、来源、安全、历史、恢复和旧书兼容。
