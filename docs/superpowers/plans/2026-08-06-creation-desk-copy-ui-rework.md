# 创作台文案与阶段总纲界面返工实施计划

> **执行方式：** 由当前 Codex 在本会话内逐项实施和复核；项目规则禁止调用其他开发 Agent。

**目标：** 修复阶段总纲竖排和大卡片堆叠问题，并把创作台、设定大纲及 AI 回复中作者可见的抽象说法改成容易理解的中文。

**实现方式：** 固定界面文案直接改写；历史规划和 AI 回复通过只读展示函数转换，作者原文、编辑框内容、数据库和正式版本保持不变。阶段总纲使用独立布局类，不再复用章纲的 48px/90px 网格样式。

**技术栈：** React、TypeScript、原生 CSS、Vitest、Testing Library。

## 全局约束

- 活动 release：`wm-longform-r1-20260719-003435-e4d7b8b7`。
- 保留当前所有未提交修改，不重置、不覆盖、不删除任何既有工作。
- 不修改迁移、生产书籍数据、作者正文、作者输入或正式规划原文。
- 不新增依赖，不改变创作台五个页签、URL、数据 Schema 或 API。
- 作者看到的固定说明必须具体、简短；不得显示“边界、正史、候选、投影、落库、契约”等内部表达。
- 创作内容中的必要专业词不做全局粗暴替换，只对明确的作者沟通短语做只读转换。
