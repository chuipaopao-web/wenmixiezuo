# 作者可读展示层实施计划

> **release_id：** `wm-longform-r1-20260719-003435-e4d7b8b7`
> **任务：** `UX-20260725-02`
> **design_review_id：** `DR-20260725-02`
> **唯一负责人 / 复核人：** 当前 Codex

## 目标

把聊天、规划、图谱、资料库和版权研究页统一改为作者可读的中文结果视图。内部 ID、JSON 字段、模型协议、哈希和来源指针继续保留在数据库及审计记录中，但不再进入普通作者主视图；有价值的依据、分歧、风险和未知项仍可按需查看。

## 不做什么

- 不删除或改写历史聊天、讨论意见、正文、正史、投影或研究记录。
- 不修改数据库 Schema、RAG、模型绑定、岗位数量、创作流程或 AI 智囊团。
- 不通过再次调用模型“总结”已有结果，不产生 Token 或现金费用。
- 不把“去技术化”实现成固定字数截断，不丢弃少数意见、事实冲突和重大风险。

## 允许与禁止文件

- 允许：当前产品/接口/验收/决定/任务/审计文档；`apps/api/src/application/chat`、`apps/api/src/application/discussions`、相关 HTTP 读模型；`apps/web/src/app`、Web API 类型、相关测试和 release 证据。
- 禁止：既有迁移、生产数据库、API Key、来源快照、`D:\AI智囊团` 全部文件。

## 依赖与实现约束

- 依赖 DEC-013、DEC-038、DEC-049、现有有效输出合同和叙事投影。
- 服务端从含前后说明的模型输出中安全提取完整结构化结果，不能用贪婪正则误吞后续规划 JSON。
- 新消息只显示结论、关键依据、必要备选、风险/未知和下一步；技术确认 ID 留在引用与动作层，不出现在话术中。
- Web 展示层递归解析受信的 JSON 字符串、翻译字段与枚举、隐藏内部字段；原始对象仍留在内存/API审计，不回写数据库。
- 图谱和版权页优先使用专用作者视图模型，不把通用对象遍历器当最终产品界面。
- 历史消息必须兼容：旧 `fallback` 的完整回复不能继续把模型协议、转义 JSON 或两份原始长意见直接展开到聊天主视图。

## 任务 1：作者展示合同与失败测试

1. 在决定、产品和 API 规格中冻结“审计原件保留、普通作者视图去技术化、依据按需展开”的边界。
2. 为嵌入式结构化回复、历史 fallback、投影记录、嵌套 JSON 和版权记录增加失败测试。
3. 验收：测试能稳定复现截图中的 `title/goal/beats/hook`、`projection id`、`content json`、UUID 和英文枚举泄露。

## 任务 2：聊天有效输出修复

1. 用字符串/转义感知的平衡括号扫描，从包裹文本中提取有效版本化 JSON 对象。
2. 让新讨论消息只保存自然主结论；结构化详情继续放有效输出引用，fallback 不暴露原始协议或整组原始意见。
3. 支持不带 UUID 的自然确认当前方案，内部仍绑定当前书的唯一待确认决定。
4. Web 对历史 fallback 做只读兼容投影，隐藏模型供应商/模型 ID 等聊天噪声。
5. 验收：不新增模型调用；未来消息和现有生产消息均不显示 JSON/代码/内部 ID，有价值的备选、风险、问题仍可查看。

## 任务 3：五类工作台作者视图

1. 新建纯函数展示模块，集中处理技术字段、中文字段、枚举、嵌套 JSON 和空状态。
2. 规划/资料库使用递归作者内容投影；编辑时仍操作原始业务值，不能因显示过滤丢字段。
3. 图谱建立按关系、情绪、主线、支线、钩子/伏笔、信息差区分的专用卡片，只展示章节、状态和有意义内容。
4. 版权/研究按来源、主张、版权结果分别展示自然字段，隐藏哈希、内部 ID 和存储时间戳。
5. 验收：普通界面不出现内部英文键、原始 JSON、UUID/哈希、owner/book/source/model 等审计字段；“尚未提取”必须自然显示，不能渲染一坨空对象。

## 任务 4：完整验证与证据

执行：目标单测、Web/API 类型检查、全量测试、生产构建、迁移连续两次、Repository/跨书/恢复相关测试、运行探针、正式验收和 `git diff --check`。保存 evidence 文档并提交；失败立即修复后重跑。

## 停止条件

- 过滤导致事实、分歧、风险或可恢复审计原件丢失；
- 显示代码回写原始数据或破坏规划编辑；
- 跨书信息泄露、正史/正文被修改、需要新付费/密钥/迁移/重大架构变化；
- 为美化界面静默伪造模型结果或投影状态。

## 回滚方法

应用与 Web 展示改动可通过单次非破坏性 Git revert 回滚；没有迁移和数据写入，不回滚历史消息、讨论意见、正史、正文或投影记录。若专用作者视图失败，临时退回经过技术字段过滤的安全只读卡片，不退回原始 JSON 直出。
