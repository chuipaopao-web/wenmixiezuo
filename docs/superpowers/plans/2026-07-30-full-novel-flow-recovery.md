# 《这游戏上线就给钱》全流程恢复与验收计划

> 执行方式：由当前 Codex 单独串行完成，不调用其他开发 Agent，不触碰 `D:\AI智囊团`。

**目标：** 使用现有开书资料，通过产品真实 API、Worker、模型调用、版本与确认流程，完成并保存设定大纲、剧情总纲、第一卷卷纲、前十章章纲和十章正式正文，保证前端能够读取和展示。

**原则：** 不直接向数据库伪造最终成品。所有创作产物必须经过产品的会话、讨论、候选、确认、规划、生产、审校和结算路径；允许用测试驱动方式修复阻断流程的缺陷。每一步以数据库/API/前端三方证据闭环为准。

**技术栈：** React、TypeScript、Vite、Fastify、SQLite、独立 Worker、REST/SSE。

---

## 任务一：冻结真实基线

**允许文件：**
- `scripts/tmp-*.mjs`
- `data/**`（仅通过产品运行时写入）
- `artifacts/**`

1. 核对服务健康、活动书、活动主编/副编、模型绑定和预算。
2. 记录现有会话、任务、设定工作区、规划版本、章节及正文版本数量。
3. 为本轮建立唯一验收目录并保存基线 JSON。

**通过：** 能从 API 和 SQLite 得到一致的基线；不能连接、书籍隔离错误或模型不可用则先修复。

## 任务二：跑通设定大纲闭环

**主要文件：**
- `apps/api/src/application/chat/conversation-service.ts`
- `apps/api/src/application/discussions/discussion-pipeline-service.ts`
- `apps/api/src/application/knowledge/setting-outline-workspace-service.ts`
- `apps/api/src/application/knowledge/setting-baseline-service.ts`
- `apps/web/src/app/App.tsx`
- 对应测试文件

1. 按相互关联的设定项分批构造前端同构资料包。
2. 通过正常消息 API 发起主编主持、双异模型编剧讨论。
3. 轮询到真实终态，检查结构化 `workflowArtifact` 与候选写回。
4. 模拟作者确认候选，逐项晋级为已确认；不适用项必须有明确理由。
5. 确认设定基线版本，并验证前端 API 展示的是中文内容而非内部 JSON。

**通过：** 所有必需设定均为已确认，设定基线版本非空，前端能看到完整内容；任何只生成聊天却不写回的情况都算失败。

## 任务三：跑通剧情分层规划

**主要文件：**
- `apps/api/src/application/planning/**`
- `apps/api/src/application/discussions/**`
- `apps/web/src/app/App.tsx`
- 对应测试文件

1. 以已确认设定为依据讨论并确认剧情总纲：全书核心冲突、阶段推进、主角弧、终局方向。
2. 讨论并确认第一卷卷纲：本卷目标、阶段冲突、关键转折、卷末状态。
3. 讨论并确认前十章章纲：每章目标、冲突、推进、结果、钩子和自由创作区。
4. 验证总纲、卷纲、章纲在粒度和内容上互不重复。

**通过：** 三类活动规划版本均可由前端读取；10个章节规划齐全且与开书标签和设定一致。

## 任务四：生成并结算十章正文

**主要文件：**
- `apps/api/src/application/creation/**`
- `apps/worker/src/**`
- 对应测试文件

1. 逐章生成写作工单和最小资料包。
2. 单一活动写手生成完整暂存稿。
3. 运行硬检查及事实、文学、体验三异模型点评。
4. 处理返工，模拟作者确认，完成正式版本和正史结算。
5. 每章后检查人物、资源、时间线和下一章依赖，防止错误传播。

**通过：** 10章均有正文正式版本、审校证据和结算记录；前端正文目录可读，内容非占位、非模型 JSON、非重复章节。

## 任务五：前端可见验收与回归

**主要文件：**
- `apps/web/src/**`
- `tests/integration/experience/**`

1. 验证设定、总纲、卷纲、章纲、正文均在对应页面显示。
2. 检查内部枚举、英文键、转义 JSON、重复字段和空白占位不泄漏。
3. 保存 API 快照、数据库快照、测试日志和必要页面截图。
4. 运行类型检查、自动测试、构建、迁移空库/升级、运行与恢复验证。

**通过：** 用户从书架打开该书即可检查全部产物；所有门禁有新鲜日志证据。
