# 文秘写作生产创作链真实性补缺实施计划

> 执行者：当前 Codex 单独开发。项目规则禁止调用其他开发 Agent，本计划在当前任务内连续执行。

**目标：** 在不改变十一岗和本地模块化单体架构的前提下，补齐任务/模型调用恢复栅栏、正史事务、切片投影、混合RAG、结构化事实、长篇结算、三席并发与主编综合的真实生产接线。

**非目标：** 不删除岗位，不删除epoch/候任机制，不跳过正式三席，不把讨论写入正史，不调用按量付费，不伪造E3/E4，不触碰 `D:\AI智囊团`。

**release：** `wm-longform-r1-20260719-003435-e4d7b8b7`

**design_review_id：** `DR-20260720-03`

## 阶段1：冻结审计与任务合同

- 写入本审计、DEC-040和任务账本。
- 验证Skill审计器、基线全测和Git清洁度。
- 回滚：仅revert文档，不影响数据。

## 阶段2：任务、模型调用与预算恢复栅栏

- 新增0020迁移：任务lease token/attempt审计、模型结果、调用调和记录。
- Worker领取、续租、checkpoint、完成和失败增加owner/book/token/attempt/expiry/editor epoch CAS。
- 成功结果不可变持久化；未知结果阻塞重试；预算只允许`reserved→settled|released`。
- 增加启动及周期过期恢复入口，防止任务永久停在working。
- 测试：晚到响应、双领、续期失败、重启、结果复用、未知结果、预算守恒、跨书。

## 阶段3：正史事务与确认幂等

- 权威读取移入`BEGIN IMMEDIATE`，更新校验影响行数和预期状态。
- 章节确认、正文选定、事实激活、正史修订、章节终态、书籍revision和审批门禁形成原子状态机。
- 文件读取留在事务外；失败不留下半正史。
- 测试：双击确认、双窗口旧revision、故障注入、跨书、重复请求、外键完整性。

## 阶段4：正史后切片与投影闭环

- 结算事务写索引请求；协调器从SQLite和不可变正文组装全书来源，构建新快照。
- 覆盖、哈希、邻接和revision探针通过后投递FTS/vector并原子切水位；失败保留旧水位。
- 测试：新增章节仍召回首章、半快照、投影崩溃、删除重建、vector降级、1500章容量。

## 阶段5：岗位混合RAG生产接线

- 为讨论、对话回复、主笔、事实/文学/体验点评建立各自查询计划和来源白名单。
- 用`HybridRetrievalService`与`RoleContextCompiler`生成H/E/I最小资料包；保存计划、命中、来源和上下文包。
- 测试：张三/天安城/宣战规则、同名、否定、旧伏笔、无答案、跨书、通道消融、Token预算和创造性非劣效构造集。

## 阶段6：结构化事实与超长篇结算

- 增加正文事实抽取Schema和证据跨度；梦境、推测、角色观点不自动进入硬事实。
- 作者确认后按A/B/C/D门禁晋升；阶段边界触发卷/故事弧结算、滚动计划和连续性快照。
- 测试：人物状态、关系、规则、地点、伏笔、时间线、冲突隔离、来源闭环、旧阶段逐级回查。

## 阶段7：三席并发、主编综合与真实性修复

- 三席保持独立模型和完整当前稿，并发调用且各自保存上下文、预算和证据。
- 活动主编只读取三份报告综合修改单；缺席、同源、坏Schema或主编不可用即阻塞。
- 试写只走明确临时快速模式；正式章节不降级。
- 修复候任模型能力检查、绑定恢复校验、无来源版权“未评估”、伪标点hook门禁和迁移文件删除检测。
- 测试：一席超时、异模型、异议保留、接管不可用、快速模式不入正史、版权真实性、迁移防篡改。

## 阶段8：全量验证、提交、备份与关机

- 每阶段执行类型检查、目标测试、构建和迁移；最终执行`npm run verify`、空库/升级、Repository、跨书、恢复、运行、备份恢复与`npm run acceptance`。
- 更新规格、覆盖矩阵、release证据和任务账本；按阶段提交，最终推送`origin/main`。
- 只有全部门禁真实通过后安排Windows关机；未通过不提前完成或关机。
