# 文秘写作运行闭环补缺实施计划

> 执行者：当前 Codex 单独开发。项目规则禁止调用其他开发 Agent，本计划在当前任务内连续执行。

**目标：** 修复长篇 release 机器账本为空、LanceDB/本地嵌入仅停留在适配器测试、四通道检索未接入公开运行路径、小文秘书未使用已验证本地语义候选这四项真实缺口；完成真实套餐模型的零现金连通探针，并以全量门禁重新给出证据等级。

**非目标：** 不修改正史和正式正文；不把本地模型变成剧情成员；不自动下载未登记资产；不启用按量计费；不伪造 20/50/100 章真实文学质量或第二物理介质备份。

**架构约束：** 延续 DEC-012/019/027/030：SQLite 是权威源，LanceDB 是可删除重建投影；Worker 构建投影，API 异步查询；向量只进入 I 证据车道；小文秘书的确定性权限/风险门禁拥有最终控制权，本地模型只返回带版本、置信度和来源的候选。

## Task 3：接通向量投影 Worker

- 目标：Worker 可领取 `vector` outbox，读取有效块、生成嵌入、构建 LanceDB 表、登记 manifest、探针成功后原子切换水位。
- 不做什么：Worker 不写正史/正式正文；不让半成品索引成为活动水位。
- 唯一负责人/复核人：当前 Codex / 故障注入和重建测试。
- 允许文件：`apps/worker/**`、必要共享契约、投影测试、锁文件。
- 禁止文件：核心业务表的直接修改路径、旧迁移修改。
- 依赖：Task 2、Schema 0012。
- 实现约束：`runNext` 异步；同书稳定表名；manifest 记录模型快照/维度/行数/哈希；失败写明错误但旧水位继续服务；空快照不建假表。
- 验收：构建、崩溃重试、删索引重建、旧水位保留、跨书隔离、维度错误均有测试。
- 测试：投影 integration/fault-injection 测试及真实离线模型探针。
- 停止：LanceDB 本地模式在目标机不能稳定打开或恢复时保持降级并记录。
- 回滚：禁用 vector capability 并删除派生目录；SQLite 权威不变。

## Task 4：公开四通道检索运行链

- 目标：公开 retrieval API 真实执行查询计划→结构化/FTS/向量/关系→同源聚类→H/E/I 融合→闭环检查，并保存每通道状态。
- 不做什么：不把向量结果升级为硬事实；不把全量结果直接注入创作模型。
- 唯一负责人/复核人：当前 Codex / 金标与消融复核。
- 允许文件：`apps/api/src/application/memory/**`、`apps/api/src/infrastructure/retrieval/**`、repositories、routes、对应测试。
- 禁止文件：来源快照文档、历史迁移。
- 依赖：Task 3、现有 Schema 0013。
- 实现约束：无 vector 资产时结构化/FTS/关系继续；formal production 歧义阻断；每书活动水位和 vector manifest 必须匹配 canon revision；输出有上限和来源定位。
- 验收：张三/天安城/宣战规则、多跳、无关键词同义、否定、旧版本、无答案、通道消融、跨书、索引损坏均通过。
- 测试：retrieval 集成、对抗、跨书、降级测试。
- 停止：来源闭环或跨书阻断项不为 100% 时不激活新公开路径。
- 回滚：环境能力开关回旧 FTS 路径；新运行记录保留。

## Task 5：接入小文秘书本地语义候选

- 目标：在确定性路由之后使用同一本地语义资产提供意图、实体排序和抽取压缩候选，提高口语改写下的识别；秘书仍不能给剧情结论。
- 不做什么：不让本地模型执行命令、写库、替代老板原话、产生第十二个创作意见或学习作者审美偏好。
- 唯一负责人/复核人：当前 Codex / 路由金标与反例复核。
- 允许文件：local-assistant、chat pipeline、模型契约、资产注册、对应测试与 UI 状态。
- 禁止文件：正史写入、提示词自修改、模型权重训练。
- 依赖：Task 2。
- 实现约束：确定性高风险/点名/活动会话优先；语义候选有最小置信阈值和版本；低置信降级主编；原话/哈希完整保存；候选不可直接触发不可逆操作。
- 验收：口语剧情请求不被秘书代答；高影响短句升级；长资料不误判；点名直达；坏 Schema/模型离线降级；跨书零泄漏。
- 测试：local-assistant routing 金标、同义改写、否定、对抗与降级测试。
- 停止：任一保护操作被本地候选自动执行或老板原话丢失。
- 回滚：关闭 semantic candidate，保留确定性代码。
