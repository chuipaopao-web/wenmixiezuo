# 作品定位开书与设定优先实施计划

- release：`wm-longform-r1-20260719-003435-e4d7b8b7`
- 决定：DEC-054
- design_review_id：`DR-20260726-setting-first-onboarding-v1`
- 负责人：当前Codex，单独开发

## 实施顺序

1. 将开书契约调整为书名、频道、分类、目标读者、主要标签和必须遵守必填；旧人物与剧情字段保留兼容但允许为空。
2. 建书事务不再要求初始主角；定位资料仍版本化保存，旧书数据不迁移。
3. 主编开场改为设定大纲引导，每轮聚焦1—3个高价值问题，不提前启动双编剧、总纲、章纲或正文。
4. 开书UI删除人物、世界观和剧情表单，保留完整分类、标签与硬边界选择。
5. 规划页改为本书资料、设定大纲、剧情总纲、卷纲、章纲，并显示设定项的三种决策状态。
6. 更新契约、领域、API和体验测试，验证新书最小输入、旧书兼容和失败回滚。
7. 执行类型检查、目标测试、全量测试、构建、幂等迁移、本地运行和差异检查。

## 质量保护

- 标签目录只用于导航和发现缺口，不进入每次模型上下文，也不以完成率锁死创作。
- “故意保持未知”是合法状态；只有影响当前阶段因果和人物行动的缺口才要求立即确认。
- 剧情和正式设定仍走候选、确认和不可变版本，不能因建书或模型拆解自动成为正史。
- 旧书已有主角、世界观、地图和剧情资料继续显示，不清空、不降权。

## 回滚

应用层和UI使用非破坏性revert；本任务不新增迁移、不清理生产数据。已创建书籍及其定位、候选、正文和正史全部保留。
