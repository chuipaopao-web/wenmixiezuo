## 1. 交付目标

在保留现有开书、设定、版本、正文、三维审校、正史、任务恢复、混合检索、导入续写、图谱、资料库和取名能力的前提下，把创作主流程改造成：

开书信息 → 设定大纲 → 当前卷纲 → 当前卷事件链 → 当前事件大纲 → 当前事件章纲 → 单章正文 → 事件结算 → 卷结算 → 下一卷。

作者在每个对象旁直接输入想法、看候选、改内容和确认。左栏只显示书籍。创作台承载六个主步骤与三个辅助工具。独立对话和独立来源风险页面在替代入口稳定后退役；底层消息、附件、任务、来源、安全和恢复能力保留。

- 唯一实现负责人：当前Codex。
- 复核人：当前Codex在实现后执行与编码分开的第二轮证据复核；涉及产品取舍、团队、费用、密钥、生产恢复或永久删除时由老板最终复核。
- 允许根目录：D:\wenmixiezuo。
- 数据迁移只向前新增，不修改已合并迁移。
- 每阶段至少执行目标测试、类型检查、全量测试、构建和差异检查；涉及数据追加空库/升级/重复迁移，涉及运行追加恢复/隔离。
- E0至E4分别报告，不用短流程或构造测试宣称文学质量。
- 删除只有在新入口、旧书、恢复、安全、静态引用和运行调用全部不依赖时才允许。
- 实际付费、新密钥或登录、生产恢复、永久删除、重大架构改变需要升级老板。

## 4. 分阶段发布门槛

- P0至P3只建规格、边界和共享合同，不改作者默认流程。
- P4至P6可在功能开关下试用，旧入口仍保留。
- P7至P10只对测试书或影子策略开放。
- P11至P13完整单章生产、三审和结算通过后，才允许小范围活动书切换。
- P14新创作台成为默认，旧URL继续兼容。
- P15未获确认直接跳过。
- P16至少一个完整卷到下一卷路径、旧书和恢复通过后开始。
- P17只声明已有证据，不把E2扩张成E4。

## 5. 最终完成定义

只有同时满足以下条件，V2才可标记完成：

1. 从零创作和已有正文续写均能进入当前卷；
2. 作者能完成卷纲、事件、章纲、正文、事件结算、卷结算和下一卷；
3. 作者原话、选择、版本、任务和来源可追溯；
4. 错链、跨书、取消晚到和结果不明被正确处理；
5. 单写手、三独立审查和作者确认没有退化；
6. 左栏只显示书籍，创作台九入口可达，桌面和窄屏可用；
7. 独立页面退役后，消息、附件、来源、安全和恢复完整；
8. 旧书、旧规划、历史任务和旧URL兼容读取；
9. 类型、测试、构建、迁移、运行、恢复、隔离、规模和验收通过；
10. 创造性、人物、情绪和整体质量相对旧流程达到非劣效门槛；
11. 每项删除有独立回滚提交和零依赖证据；
12. 工作树与发布证据一致，无未说明改动。

未取得E4真实连续创作证据时，可以完成工程发布，但只能表述为“V2机制与工程门禁已通过”，不能宣称已经解决长篇小说质量。
