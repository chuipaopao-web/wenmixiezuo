# 章节式正文导入与作者原文处理计划

- `release_id`：`wm-longform-r1-20260719-003435-e4d7b8b7`
- `design_review_id`：`DR-20260802-chapter-manuscript-workbench-v1`
- 决定：DEC-089

## 目标

把正文页从“空书即打开整本巨型输入框”改成“章节目录 → 当前章原文 → AI处理候选”的常用工作流。作者可以逐章新建、粘贴或选择TXT，保存作者原文后再选择AI点评、表达优化、自然化（去AI腔）或自定义优化。

## 非目标

- 不删除既有整本TXT续写导入及其恢复记录，只将其降为可选批量入口。
- 不让点评、优化或自然化结果覆盖作者原文、自动定稿或自动进入正史。
- 不把去AI腔解释为AI作者概率，不为了“像人”故意制造错字、病句或无意义口语。
- 不修改正史、RAG、岗位数量、模型绑定、已合并迁移或生产书籍数据。

## 实施步骤

1. 规格与设计审查：登记DEC-089、作者原文权威边界、候选版本和回滚条件。
2. API客户端：复用现有卷/章创建端点，增加带类型的客户端调用，不新增数据库。
3. 正文工作台：正文页始终显示扁平章节目录；空书显示“第1章”起始位；支持添加下一章和可选批量TXT入口。
4. 单章导入：当前章支持粘贴和选择单章TXT；保存后形成不可变 `creator_kind=owner` 候选版本。
5. AI操作：增加“AI点评”“优化表达”“自然化”“自定义优化”；复用正式审校/重写任务链，保留原版本并明确等待作者采纳。
6. 验证：覆盖空书、逐章新建、TXT读取、原文保存、操作路由、旧整本导入恢复、不可覆盖、跨书和可访问性；再跑类型、全量测试、构建、迁移与运行验证。

## 停止与回滚

发现作者原文被覆盖、AI结果自动定稿、跨书写入、同一点击重复建章、旧导入恢复不可用，或需要新密钥/付费/生产数据恢复时停止。回滚Web工作台与客户端调用即可；既有章节、正文版本、任务、审校和导入记录全部保留。
