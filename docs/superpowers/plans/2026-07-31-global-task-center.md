# 首页全局任务中心实施计划

> 适用 release：`wm-longform-r1-20260719-003435-e4d7b8b7`

**目标：** 将任务中心从单书工作台移到首页，按书籍聚合展示后台任务、预算与待确认事项，并保证查看、取消、重试和确认始终作用于正确书籍。

**不做：** 不改变 Worker 调度、任务状态机、预算算法、正史规则或模型绑定；不接触 `D:\AI智囊团`。

**实现约束：**

- 首页书架默认不加载所有书的完整工作区；只有进入“任务”页才按需加载。
- 每个任务引用必须同时携带 `bookId` 与 `taskId`，不得依赖当前打开书籍猜测归属。
- 单书左栏删除“任务”；书内已有后台任务继续运行。
- 多书加载允许单书失败，其余书籍仍应显示，并给出可读提示。
- 沿用现有浅绿色视觉、窄侧栏和固定视口，不引入第二套导航样式。
