# 《少女的实验笔记》开书与逆向规划全链路计划

**release_id:** `wm-longform-r1-20260719-003435-e4d7b8b7`
**design_review_id:** `dr-wm-20260805-girl-experiment-notes-e2e`
**唯一负责人/复核人:** 当前 Codex（单人串行）

## 目标

修复长开书表单点击创建后缺少可见反馈的问题；按老板截图中的开书资料幂等创建唯一一本《少女的实验笔记》；生成并导入约两万字原创正文；完成分章确认、逐章逆向章纲、设定候选与三席设定讨论，并将全部结果保留在前端供老板检查。

## 不做什么

- 不创建第二本同名测试书；重跑必须复用已有书籍。
- 不把逆向章纲、模型建议或未确认设定直接写入正史。
- 不访问、修改、停止或重启 `D:\AI智囊团`。
- 不打印、记录或提交任何 API Key。
- 不把未成年阶段写成恋爱关系；17岁阶段只处理救助、边界、成长和社会重建。

## 允许文件

- `apps/web/src/app/App.tsx` 及对应样式、API客户端与UI测试。
- 开书、续写导入、逆向分析和设定讨论相关的API/Worker代码与测试。
- `scripts/evaluation/` 下本次幂等全链路脚本。
- `data/evaluation-inputs/` 下本次原创正文输入。
- 当前计划、测试证据、任务账本与覆盖矩阵。

## 禁止文件

- `D:\AI智囊团` 下全部文件。
- 与本问题无关的迁移和来源快照文档。
- 已合并数据库迁移。

## 依赖与约束

- 只使用 `127.0.0.1` 的文秘写作API和Web。
- 创建前按书名查询；存在时复用，不存在时创建。
- 正文原文为权威输入，逆向章纲和设定均为带来源的候选投影。
- 真实模型调用只走环境变量配置的火山方舟 Agent Plan；缺凭证时只能完成确定性测试，不能冒充真实成员讨论。
- 逐章分析，禁止把整本两万字一次性注入单个模型调用。

## 实施步骤

1. 为无效长表单提交增加失败UI测试：顶部可见缺项、自动聚焦/滚动到第一个无效字段。
2. 最小修复开书表单校验反馈，验证已完整填写时只提交一次。
3. 建立幂等全链路脚本，固化截图中的频道、分类、角色、故事方向、题材、标签和边界。
4. 生成约两万字原创正文，按章节标题导入；预览、确认后校验章节数、字符数和不可变正文版本。
5. 逐章运行逆向分析，核对人物、剧情简介、冲突、情绪、伏笔、设定候选和来源。
6. 启动设定讨论，核对主编与两名异模型编剧的独立建议、主编综合及未确认状态。
7. 核对前端书架、正文、规划、资料库、任务和对话均能读取已保存数据。

## 验收标准

- 点击创建但存在缺项时，页面顶部立即说明缺哪些字段并定位首个缺项；不再表现为无响应。
- 数据库与书架只存在一本《少女的实验笔记》。
- 开书资料与截图逐项一致，且故事方向明确标记为软参考。
- 正文总量约两万中文字符，分章后可在正文列表逐章查看。
- 每章都有可追溯逆向章纲；原文未被分析流程改写。
- 设定大纲收到开书资料与逆向章纲的候选，三席讨论真实可追踪，作者未确认前不进入正史。
- 重跑脚本不会创建重复书、重复导入或重复启动同一终态任务。

## 停止条件

- Agent Plan缺少真实凭证或模型不可用：保留书、正文和确定性分析证据，明确标记真实三席讨论未完成，不伪造回复。
- 数据库升级失败、跨书隔离失败或正文可能被覆盖：立即停止写入，保留日志并先修复根因。

## 回滚方法

- UI修复可按单文件补丁回滚，不影响业务数据。
- 全链路脚本只创建/复用本次命名书，不清理其他书；若创建阶段失败则保留可恢复任务。
- 逆向分析与设定候选均为派生层，可停用消费而不删除原始正文。
