# 当前阶段剧情工作台实施计划

**目标：** 将剧情总纲改造成只展示当前阶段、按需浏览剧情库、三人三案、作者选择后再由主编整理的工作台。

**不做：** 不删除旧阶段，不改正文或正史，不让模式库自动决定剧情，不创建测试书。

**负责人：** 当前Codex单独实施与复核。

1. 同步DEC-103与设计审查，验证审查合同。
2. 前端增加阶段导航、当前阶段详情、按需剧情库和“设计本阶段”入口。
3. 修复阶段编辑时覆盖其他阶段的数据损失风险。
4. 新增 `stage_outline_panel` 讨论目的，由活动主编、另一名编辑和一名编剧各输出一份独立方案，保留真实成员和模型来源。
5. 复用作者选择/融合与主编整理流程，禁止自动确认和直接生成正文。
6. 补充组件、集成、契约与回归测试；运行类型检查、自动测试、构建、迁移及本地运行验证。
7. 更新任务账本、验收证据并提交Git。

**回滚：** 移除新入口并恢复旧讨论入口；保留新增字段、历史阶段与任务数据，前端仍能读取旧 `stage_master_v2`。
