# 取名助手独立细分类实施计划

- `release_id`：`wm-longform-r1-20260719-003435-e4d7b8b7`

- `design_review_id`：`DR-20260801-local-naming-taxonomy-v2`

## 目标

把取名助手从46个合并目标升级为不少于110个独立细分类，尤其彻底拆开人工智能、机器人、仿生人、器灵、精怪、妖族、异族、神明和亡灵。每个可见类型必须能真正生成候选，而不是只改前端文字。

## 不做什么

- 不调用模型、付费API或新增岗位；
- 不改变开书资料结构、数据库、正史、正文或模型绑定；
- 不自动保存任何候选；
- 不修改或重启 `D:\AI智囊团`。

## 允许与禁止文件

- 允许：本地取名目录和生成器、取名面板专项回归、当前产品/决定/任务与release证据。
- 禁止：已合并迁移、生产书籍资料、API Key、来源快照和其他项目。

## 实现约束

1. 六个一级分组保持不变，二级目标拆成独立类型。
2. 所有可见类型具有唯一ID、名称、说明和候选映射。
3. 相近类型可以复用字根，但使用专属后缀体现用途差异。
4. “非人主角”不等于人工智能、器灵或精怪，默认不替作者猜测具体物种。
5. 候选继续保持确定性、可换批次、可排除、无业务写入。

## 验收与停止条件

- 先建立失败测试，锁定旧目录数量、合并项和空候选；
- 遍历全部可见细类，逐类生成候选并校验ID唯一；
- 回归开书填入和书内复制界面；
- 执行类型检查、全量测试、构建、迁移幂等、运行、备份恢复和正式验收。
- 出现空类别、重复ID、跨书写入、候选进入正史，或需要新密钥/付费/生产恢复/重大架构变更时停止。

## 回滚

Git回滚目录、映射和专项测试；无Schema或生产数据回滚。
