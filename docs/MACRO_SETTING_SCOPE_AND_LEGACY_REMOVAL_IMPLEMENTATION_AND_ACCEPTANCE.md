# 宏观设定边界与早期内容移除：开发与验收清单

更新时间：2026-08-22

## 一、老板本次决定

- 设定页只设计跨剧情、跨人物仍然成立的书籍宏观规则，不在这里预设具体角色、配角类型、人物功能、人物关系或关系变化。
- 角色与人物关系跟随分卷、事件、章纲和正文逐层形成；正文实际发生后再通过结算进入正式人物与关系资料。
- 早期设定内容必须能从当前设定中移除；移除后不再进入当前临时资料包，但历史版本保留，正文与已经形成的正史不删除。

## 二、开发清单

### 1. 设定对象边界

- [x] 核心四项改为“世界舞台、社会运行与秩序、规矩与代价、边界与留白”。
- [x] 从新设定库下架“主角底板、优势与缺陷、配角类型、人物关系”和言情人物关系进展类条目。
- [x] 删除新库中的“人物与命名”板块；世界层面的语言、称谓或命名制度可以作为宏观条目或自定义规则，但不建立具体人物名单。
- [x] 题材推荐只提供该题材的客观世界机制，不把人物关系、关系阻力、人物生活圈或具体剧情条件列为设定必选项。
- [x] 保留地理、治理、社会结构、力量/科技规则、资源经济、组织制度、信息传播和题材世界机制等宏观条目。
- [x] 旧书已填写但已下架的条目只进入“早期设定内容”，不自动回到本轮设计队列。

### 2. 早期内容移除

- [x] 每条有当前内容的早期设定提供“从当前设定移除”操作。
- [x] 操作前明确提示：当前内容、待定候选、临时资料包引用会移除；历史版本和正文不删除。
- [x] 后端使用独立的单项移除语义，按 `owner_id + book_id + item_key` 限定目标。
- [x] 移除后将当前条目归零为待讨论，清除当前内容、确认时间、来源和待定候选。
- [x] 与该条目当前版本对应的活动设定子句归档，版本历史仍可查询。
- [x] 不用永久删除，不要求输入 `YES`；“清空全部设定”继续保留原有二次确认。

### 3. 临时资料包与工作流

- [x] 临时资料包仍只读取其他已确认且有内容的当前条目。
- [x] 单项移除后，新发起的下一项设计不再收到该条目；已有任务快照仅作审计，不回写旧内容。
- [x] 已下架人物类旧内容未移除前可在早期区查看，但不作为新库必选项；移除后从早期区消失。
- [x] 主编仍只在本轮逐项设计全部完成后开放审查。

### 4. 页面与交互

- [x] 新库入口与说明明确写出“这里只设计世界如何运行，不设计谁和谁发生什么”。
- [x] 早期内容卡片有清晰但克制的移除入口和就地确认区，键盘可操作，忙碌与失败状态可见。
- [ ] 360 / 390 / 430px 下按钮不溢出，确认文案与旧内容可完整阅读。（代码与自动化交互已覆盖；本机浏览器连接被 Windows 沙箱辅助程序故障阻断，待恢复后补人工截图。）
- [x] 删除已下架目录、旧推荐和相关无效文案；不保留双入口。

### 5. 文档同步

- [x] 更新当前产品、数据模型和交接文档中的核心键与角色边界。
- [x] 明确旧人物类键只做兼容读取和历史移除，不迁移、不永久删除作者版本。

## 三、逐项验收清单

### A. 目录验收

- [x] 通用和已有正文续写都只要求四项宏观核心设定。
- [x] 言情、都市等题材不再推荐人物关系、关系阻力、关系成长或人物生活圈。
- [x] 完整设定库搜索不到“配角类型”“人物关系基本原则”“主角底板”。
- [x] 旧书的上述已填内容仍出现在早期区，未填空壳不显示。

### B. 删除与数据验收

- [x] 点击早期条目移除先展示影响说明，取消不产生写入。
- [x] 确认后当前内容为空、状态归零、卡片消失，页面给出成功反馈。
- [x] 删除接口拒绝不存在条目，且无法跨账号或跨书影响数据。
- [x] 删除后历史版本数量与文本不变；正文、正式结算不变。
- [x] 删除后活动设定子句不再参与检索，下一次临时资料包不含该项。
- [x] API 失败时卡片和内容仍保留，允许重试。

### C. 回归与发布前验证

- [x] 相关设定目录、工作区服务、API 和页面测试通过。
- [x] Web 类型检查与构建通过。
- [x] API 类型检查与构建通过。
- [ ] 浏览器检查桌面与 360 / 390 / 430px：折叠库、早期卡片、确认/取消、成功移除均可用。（两次连接均被本机沙箱辅助程序故障阻断。）
- [x] 检查差异仅包含本次功能文件和必要文档，不覆盖工作区已有改动。

## 四、验证结果

- 全量测试：182 个测试文件、776 项测试全部通过。
- API、Worker、Web 与测试 TypeScript 检查通过；contracts、API、Worker、Web 生产构建通过。
- Web 构建只有既有的单包超过 500 kB 提示，不影响本次功能。
- 浏览器技能已按要求初始化两次，但浏览器进程都因 `windows sandbox helper_unknown_error` 未能启动；未触碰生产环境。

## 五、风险说明

- 本次不改数据库结构，不永久删除版本或正文，不改变账号隔离边界。
- 本次改变活动设定目录与当前内容移除行为；旧键继续保留为兼容历史，避免旧书作者内容静默丢失。
- `design_review_id`：不适用（无权限、数据库语义迁移、计费、恢复或不可逆 ContextCompiler 架构变化）。
