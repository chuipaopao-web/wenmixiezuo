## 2. 逐项开发的统一完成定义

每个功能项必须依次满足以下五个状态，才能勾选为完成：

```text
待开发 → 已实现 → 已核查 → 已定向测试 → 已完成
```

- [x] “已实现”：前后端或文档改动完整，不是占位按钮、假数据或只做 UI。
- [x] “已核查”：检查业务闭环、异常路径、移动端、跨书隔离、版本和权限。
- [x] “已定向测试”：运行直接受影响测试、类型检查和构建；保存命令与结果。
- [x] “已完成”：无已知阻断问题，相关旧实现已处理，验收项已有证据。
- [x] 每完成一个阶段，更新本清单并报备完成项、未完成项、测试结果和发现的问题。
- [x] 不允许先把所有代码写完，最后一次性声称全部完成。
- [x] 不允许用字段存在、静态夹具或截图替代真实业务闭环测试。
