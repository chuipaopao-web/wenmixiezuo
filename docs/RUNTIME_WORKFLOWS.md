# 运行时工作流与状态机

## 1. 统一任务状态

```text
pending → queued → working → succeeded
                    ├→ paused → queued
                    ├→ failed → queued（仅可安全重试）
                    ├→ blocked
                    └→ cancelled
```

任务包含书籍隔离键、幂等键、上游版本、负责人、预算、阶段、检查点、attempt、租约和错误码。状态只由真实数据库和Worker事件驱动。

## 2. 开书

校验全部作者输入 → 建立书籍草稿 → 作者确认 → 单事务创建书籍/定位/14名成员/模型绑定/预算/设定工作区 → 排队首个设定提案。失败回滚整笔事务。

## 3. 设定

当前设定项准备完整开书资料与作者本项原话 → 主编和两位编剧互不可见地独立生成 → 保存三份意见 → 作者选择/组合/自写 → 主编只按选择整理 → 作者确认 → 推进下一项。全部必要项确认后生成活动设定版本。

## 4. 分卷

编译开书、设定、上一卷结算、当前状态、节奏和作者想法 → 两位编剧独立方案 → 主编融合 → 作者编辑/确认 → 活动卷纲生效。上游版本变化会使候选过期。

## 5. 事件链与事件大纲

活动卷纲 → 生成事件序列与因果衔接 → 作者调整顺序/增删拆并 → 确认事件链。选中当前事件后，结合完整事件链、卷目标和作者意见生成事件大纲候选 → 作者融合/确认。

## 6. 当前事件章纲

先评估完整事件需要的章数和字数，再生成连续章链。每章纲冻结卷纲、事件链和事件大纲版本。作者确认整个事件章链后，最前未完成章进入正文生产。

## 7. 单章正文

准备冻结资料包 → 单一活动写手生成完整初稿 → 硬格式与边界检查 → 事实/文学/体验三席并行审查 → 形成可执行修改清单 → 作者编辑或定点修订 → 作者定稿 → 不可变正文版本 → 章节结算。硬检查同时拦截内部治理说明和最近5章大段模板复用；最多2轮定点修复，仍失败则阻断。

三席互不读取报告；正式正文不批量跨章生成。结果未知时停止自动重试。本地确定性写手只用于显式测试，正常作者流程缺少创作模型时直接提示配置模型，不生成伪正文。

## 8. 事件与卷结算

事件所有章节定稿后，按正文实际内容汇总结果、代价、人物变化、伏笔和下一事件触发；比较计划与实际并由作者确认。卷内事件全部完成后生成卷结算、遗留问题和下一卷起点。

## 9. 续写

导入预览 → 作者核对 → 不可变原文入库 → 分析和切片任务 → 带来源的设定/状态/事件/卷候选 → 作者确认缺口 → 进入当前卷—事件流程。导入和分析不补造历史审查报告。

## 10. 失败恢复

- 租约过期：Worker恢复检查点，已成功调用不重复执行。
- 本地确定性调用中断：可证明未执行时释放预算并重试。
- 远程结果未知：进入调和，不自动重发。
- 上游版本变更：旧候选过期，正式数据不回滚。
- SQLite短暂写锁：只对上下文包落库和同任务附件绑定的明确锁冲突做最多3次有限退避；非锁错误立即失败，耗尽后保留检查点供任务恢复。
- 投影失败：正式事务保留，outbox重试重建。
- 主编切换：新epoch拒绝旧主编的迟到提交。

## 11. 已退役运行流

运行时只接受绑定明确业务对象与活动版本的作者输入和AI任务，不注册非对象化消息入口或会话任务。
