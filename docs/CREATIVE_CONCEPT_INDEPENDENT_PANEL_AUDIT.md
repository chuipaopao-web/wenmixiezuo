# 策划理念三席独立提案审查

- `design_review_id`：`DR-20260803-creative-concept-independent-panel-v1`
- release：`wm-longform-r1-20260719-003435-e4d7b8b7`
- Skill：`wenmi-longform-quality`（本次变更前完整读取）；审查依据为当前 `SKILL.md`、`references/creativity.md`、`references/evaluation.md` 与 `docs/DESIGN_GOVERNANCE_AUDIT.md`。

## 事实与边界

- 已确认事实：旧流程由单个活动主编立即生成一个策划理念，作者无法同时看到不同专业视角。
- 老板最新决定：策划理念首次由主编和两名编剧互不交流地各给一个方案，作者自行选择、组合或自拟。
- 推断：首轮保留三个独立判断可以扩大起点创意空间，但若扩展到每个设定项会增加调用成本、选择负担和上下文噪声。
- 未知项：真实三模型跨题材候选的差异度与作者选择效率尚无E3/E4证据，不能宣称文学质量已经提高。
- 不做：不让三席交叉讨论，不自动综合，不自动写入设定，不改变剧情总纲和正文生产流程。

## 痛点—机制—反例—指标

| 项目 | 内容 |
| --- | --- |
| 痛点 | 单席过早收敛，创意入口过窄；作者又不希望被连续盘问。 |
| 症状 | 页面只出现一个方案和“是否确认”，缺少可比较的真实创意判断。 |
| 根因 | 策划理念复用了普通设定项的单成员回复管线。 |
| 机制 | 专用 `creative_concept_panel`：三名真实成员各自独立调用；跳过交叉质疑和综合；逐席显示；等待作者裁决。 |
| 反例 | 时间规则、人物年龄或普通设定修订不需要三席发散，继续由主编收敛。 |
| 指标 | 恰好3份独立调用与3条成员消息；提示和上下文不含同轮其他答案；零自动设定候选；刷新不重复创建。 |
| 证据 | 自动测试、调用记录、参与者快照、消息发送者与任务检查点。 |
| 停止条件 | 候选重复率上升、内部字段泄漏、作者选择困难显著增加、三席任务不能幂等恢复或成本越界。 |

## 两轮审查

第一轮验证结构正确性：三席参与者真实存在，恰好三次独立调用，任何一席提示中都没有同轮其他输出；完成后不进入交叉质疑、主编综合或设定落库；消息携带真实成员和模型来源；任务可恢复且不重复。

第二轮验证创造性非劣效边界：三席分别从编辑定位、人物戏剧机制和异构创意角度提出方案，但不固定模板、不强制彼此差异、不扩写剧情；作者拥有选择、组合、自拟和拒绝权。变更仅扩大首轮候选空间，选择后立即恢复单一候选收敛，防止方案树无限增长。

## 回滚

停用 `creative_concept_panel` 专用路由并恢复单主编首次推荐；不得删除已经生成的消息、讨论、模型调用或作者选择记录。无需数据库迁移。
