# 单阶段剧情总纲与剧情模式库设计审查

- `design_review_id`: `DR-20260805-stage-plot-pattern-library-v1`
- Skill：`wenmi-longform-quality`（2026-08-05读取）
- 适用范围：剧情总纲、反向拆解、讨论资料包、前端规划工作台

## 问题链

痛点是旧总纲接近概括文本，缺少可验证结束条件和防偏移边界；症状是总纲与章纲趋同、编剧一次规划过远、正文中途漂移。根因不是模型强弱，而是阶段契约不完整、剧情推进方式没有可见的选择层。机制是单阶段固定契约，加一个按题材推荐但不强制的剧情模式库。

## 方案与反例

采用“一个主模式、最多两个辅助模式”，同时保留不选、自定义和自由发挥。不能把“扮猪吃虎”“追妻火葬场”等模式写成必须逐点执行的章法，否则会牺牲人物生命力和合理惊喜。不能让反向拆解为了填满字段而发明正文中不存在的模式、伏笔或因果。

## 两轮审查

第一轮完整性审查：阶段目标、开场状态、冲突、起承转合、结束验收、防偏移边界均可单独检验；与章纲的逐章任务层次分开。

第二轮创造性审查：硬约束只覆盖已确认事实、结束承诺和不可破坏因果；模式、情绪、表现手法与局部节奏保留为软参考和自由区。允许作者组合、拒绝或自定义模式。

## 证据、指标与停止条件

当前证据等级为E0工程契约与兼容性验证，不声称已证明长篇质量提升。验收关注：旧总纲可读、新字段可保存、题材推荐可解释、反向拆解不臆造、单阶段不超过50章、前端无内部JSON。若模式选择降低方案多样性、造成明显套路化或增加无效上下文，则回退为仅搜索浏览、不自动推荐。
