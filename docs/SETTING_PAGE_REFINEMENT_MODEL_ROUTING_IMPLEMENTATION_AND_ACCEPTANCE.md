# 设定页精简交互、重新设计与模型路线：开发及验收清单

更新时间：2026-08-22

## 一、用户可见目标

- 作者在接近全屏宽度的设定工作区中，只勾选本书确实需要的宏观设定条目。
- 勾选完成后无需再经过整页弹窗，直接进入按顺序逐项设计。
- 作者能正常选择可用编剧；已有方案可一键重新设计，系统使用调用时的最新临时资料包，并明确要求给出不同方案。
- 自写、现成内容和留白入口均可展开、收起、恢复，不形成页面死路。
- 全部条目完成后只显示“全部设计完毕后，交由主编审核”；主编确认正式设定后可进入分卷。

### B. 编剧选择与方案重做

- [x] 找到并修复编剧席位无法勾选的真实原因；可用席位可选，不可用席位保留明确原因，至少选择一席才能开始。
- [x] 每份编剧方案下方增加“重新设计”按钮，避免与确认/采用主操作混淆。
- [x] 点击“重新设计”立即为当前编剧创建新任务，不要求重新打开选席面板，不抹掉其他成员成功方案。
- [x] 重做任务调用时重新编译当前 `owner_id + book_id` 的最新临时资料包；修改或新增已确认条目后不得复用旧包。
- [x] 重做任务携带上一方案摘要/指纹作为排除依据，明确要求产生实质不同的新方案；新结果替换该席当前候选，旧任务快照保留审计。
- [x] 重复点击、运行中、失败、刷新恢复均有状态和就地重试，不能重复创建同一轮任务。

### C. 模型路线

- [x] API Key 只引用环境变量；不写入数据库、日志、文档、测试夹具输出或 Git。
- [x] 四名编剧保持互不相同的模型签名；不可用凭证只禁用对应席位，不阻断其他可用席位。
- [x] 存量书在安全升级路径上更新活动绑定；运行中任务继续使用冻结快照，不改写历史调用证据。

- [x] 所选设定项全部确认前，主编审核按钮不可用；全部完成后开放。
- [x] 主编审核通过并确认当前正式设定基线后，规划状态进入可设计分卷阶段，页面可跳转分卷。
- [x] 主编提出问题时保留作者内容并给出处理入口；处理完重新审核，不静默放行。
- [x] 设定候选与临时资料包在主编确认前不进入正式设定基线；确认后使用精确活动版本。

## 三、逐项验收

### 1. 页面状态

- [x] 初始状态：全宽布局、标题和勾选说明正确，首屏唯一主操作为“我已确认勾选完毕”。
- [x] 选择状态：核心/题材推荐默认勾选，其他条目可选；确认后无二次弹窗，直接进入第一项。
- [x] 自写/留白：展开后可关闭，再次展开内容仍在；长内容与长错误不溢出。
- [x] 方案状态：可正常选择编剧、启动、查看候选、采用和重新设计。
- [x] 失败状态：单席不可用或失败不清空其他方案，并提供恢复动作。
- [x] 完成状态：只显示“全部设计完毕后，交由主编审核”。

### 2. 任务与资料包

- [x] 首次设计和重新设计分别产生正确任务；运行中重复点击不产生重复任务。
- [x] 重新设计使用新资料包指纹，并包含与上一方案实质不同的明确约束。
- [x] 修改已确认条目后再重做，任务收到修改后的摘要；清空后资料包为空。
- [x] 旧方案、其他书、其他用户、未确认候选不进入新任务上下文。

### 3. 模型与安全

- [x] 普通 AI 岗位解析到 Coding Plan provider/plan，高级编剧解析到 Agent Plan + Kimi K3。
- [x] 缺少任一路线凭证时返回作者可读的席位不可用原因，不泄漏环境变量值。
- [x] 没有明文 API Key 出现在 Git 差异、日志断言和任务上下文。

### 4. 审核与分卷

- [x] 未完成设定时不能主编审核或进入分卷。
- [x] 全部完成 → 主编审核 → 作者处理问题/确认 → 正式基线 → 分卷入口可用，全链路通过。
