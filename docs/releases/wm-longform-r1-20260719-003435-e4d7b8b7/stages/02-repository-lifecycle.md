## 设计复核与修正

1. 开书预计规模原先只依赖数据库约束，错误会泄漏为底层SQL异常；现增加应用层1,000至10,000,000整数校验。
2. 动态标签、别名、实体Schema、资料缺口和语义置信度原先缺少完整输入边界；现拒绝空命名空间、空适用对象、空Schema和越界置信度。
3. 清理策略原先只有表结构，没有可执行的安全边界；现明确作者可见聊天、稿件、规划、设定和研究资料只能归档/校验/恢复，只有白名单内可重建投影可在任务结束7天后幂等清理。
4. 旧事实迁移不再猜测世界时间或人物知情时间，统一保留原权威等级并标记 `temporal_completeness=partial`；迁移是显式、幂等应用动作，不在Schema迁移中伪造正史。
