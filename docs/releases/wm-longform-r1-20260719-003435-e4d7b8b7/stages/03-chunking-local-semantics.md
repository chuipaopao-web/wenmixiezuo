## 设计复核与修正

1. SQLite `unicode61` 不会自动把中文长句按人物名切词，直接查询“张三”可能漏掉“张三在天安城外……”；FTS投影现加入确定性中文单字/双字词元，最终显示和证据仍回到未改写原始片段。
2. 仅安装LanceDB依赖不能证明向量可用；能力探针现同时要求向量运行时、嵌入运行时和哈希验证的本地嵌入资产。当前资产尚未配置时明确返回 `vectorSearchAvailable=false`。
3. Transformers.js默认允许远程模型；正式适配器在创建管线前强制 `allowRemoteModels=false`，并校验离线目录聚合哈希和输出维度，避免运行时静默下载或混用向量空间。
4. 结构切片禁止静默NFC改写来源；来源必须先固定规范化与哈希，切片器只产生字节范围、父子/邻接和检索投影。

## 实现结果

- 新增Schema 12：结构节点、检索块、实体绑定、切片快照/来源、投影outbox/job/watermark、嵌入模型快照、LanceDB清单和逐书能力状态。
- 中文结构切片使用350—700字符初始策略上界、父块3,000字符、段落/句末边界、默认零复制重叠，并保留UTF-8字节范围、分隔符范围、叙事模式和边界置信。
- 重切片创建不可变快照；来源哈希、覆盖、无重叠、父子和邻接探针通过后才进入ready。探针失败事务回滚，上一水位保持活动。
- FTS投影按书、快照和正史水位过滤；Worker outbox只在ready来源及同水位探针通过后原子切换活动水位。
- 安装锁定 `@lancedb/lancedb 0.22.3` 与 `@huggingface/transformers 3.8.1`；LanceDB支持本地落盘、重开、重建及书籍/快照硬过滤。
- 提供真实离线Transformers嵌入适配器、确定性测试嵌入和Null降级；缺资产不访问网络、不把向量冒充硬事实。
- 小文秘书工具模型先建立严格候选合同和确定性/Null实现，只输出意图、实体候选、否定或抽取式压缩候选，不执行SQL、路径、工具和正史写入。
