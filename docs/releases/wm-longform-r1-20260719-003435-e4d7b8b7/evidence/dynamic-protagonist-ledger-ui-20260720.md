## 根因与修复

1. 数据表的 `category` 原本就是按书自由字符串，但Web把八个示例分类硬编码成所有书共用的空模板。本次改为只渲染当前书实际存在的分类，已有英文键只做中文显示兼容，自定义分类直接显示。
2. 已结算主角专用事实在没有预建档案时原本会被跳过。本次只对同书活动角色、活动正史绑定和 `protagonist_state/delta` 关系确定性自动建档；普通人物事实、草稿、聊天和模糊描写不能触发。
3. 无法可靠分类的事实使用 `unclassified`，页面显示“待归类”，并按 `profileId:logicalKey` 建立去重资料缺口。作者确认分类新增状态修订，保留原值、单位、权威层、事实ID、正文版本与历史，然后关闭问题。
4. 已归档主角档案不会被后续投影静默恢复，避免违背作者的归档决定或触发唯一键错误。
5. 右栏删除重复的小文秘书工具卡，只显示11名创作成员；聊天中的历史系统来源和新本地回执仍统一显示为小文秘书。
6. 字号四档改为 `1.00/1.10/1.20/1.32`，标准档提高10%；团队姓名、职责和状态基线同步提高，侧栏宽度不变。
