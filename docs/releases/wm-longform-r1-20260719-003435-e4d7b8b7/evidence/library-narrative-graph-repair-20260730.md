# 资料库角色详情与叙事图谱修复证据

- Release：`wm-longform-r1-20260719-003435-e4d7b8b7`
- 决定/审查：DEC-041；`DR-20260720-04`
- 日期：2026-07-30
- 书籍：`《这游戏上线就给钱》`

## 故障基线

1. 资料库实体卡只显示类型、名称和别名，虽然数据库已有角色事实和主角状态，但没有按 `subject_entity_id` 联结到卡片。
2. 人物关系事实使用 `relationship.temporary_alliance`，投影重建只识别 `relationship:`，所以关系事实存在而图谱为空。
3. 五类叙事投影只保存 `not_extracted` 空壳，规划章纲、章节结算状态和三席审校中的真实信息没有被投影成作者可读内容。
4. 已确认设定和开书资料没有进入资料库聚合读模型，作者无法在资料库核对规划阶段已经确认的非剧情设定。

## 修复

- 资料库聚合 API 增加开书资料、已确认设定、事实来源章节，并严格按同书 `owner_id + book_id` 联结实体、事实、章节和关系。
- 角色、地点、势力、道具、事件和规则卡片显示已结算事实、主角状态、来源章、证据等级和权威状态；重复事实去重。
- 没有真实事实的实体明确显示“尚无已结算的详细事实”，不使用模型猜测或无来源补写。
- 关系投影兼容 `relationship:` 与 `relationship.` 两种已存在的合法关系键。
- 叙事投影从选定章纲、章末状态、事实审校、文学审校和体验审校重建计划/实际两条轨；不把审校推断写回正史。
- 增加只重建可派生投影的维护脚本和只读审计脚本。
