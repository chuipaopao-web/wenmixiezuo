## 实现摘要

- Schema 3新增9岗位模板、Agent实例、模型快照、预算/冻结/用量、任务/依赖/阶段、模型/工具调用、主编租约和接管包。
- 9岗位为5核心加4按需专家；专家默认待命，所有实例如实显示当前共同的确定性假模型来源。
- 研究专家缺少真实联网能力时激活失败，不伪造能力；同模型复核被独立性门禁拒绝。
- 任务支持幂等键、依赖、全局单并发租约、心跳、检查点、暂停、继续、取消和失联恢复。
- 能证明调用未开始时自动重新入队；存在working调用且无可复用结果时标记 `interrupted`，普通入队拒绝。
- 模型调用前冻结Token和现金预算；未知现金费用先暂停；冻结与结算写入独立用量账本。
- `AbortSignal` 真实传入底层适配器，取消不是只改数据库状态。
- Presence从Agent启用状态、任务、阶段、模型/工具状态和心跳推导，心跳过期显示离线。
- SSE使用持久递增 `eventSeq`，连接后按 `after` 回放再轮询实时事件。
- 接管包包含活动任务、检查点、正史/定位版本、模型调用和预算；完成后epoch递增，旧指令拒绝，未结束任务同步新epoch。
- Worker使用独立进程和受限调度Repository，只领取/更新任务、阶段、事件和健康记录。
