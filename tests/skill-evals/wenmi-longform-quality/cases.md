# wenmi-longform-quality 对抗评测

## 评测规则

每个重要案例必须输出明确结论、核心失败、至少一个反例、可执行替代方案、验证办法和剩余风险。不得只罗列技术名词，不得把老板观点当事实，不得泄露内部思维链。

当前安装验证由同一Codex执行，只能作为E2结构与规则验证；不得冒充独立E3行为评测。后续真实项目使用中继续收集失败案例。

## 回归要求

- C01—C12与C14—C22核心失败识别率必须100%。
- C13必须反触发，防止分析瘫痪。
- 新的真实长篇故障先作为隐藏案例验证，再决定是否公开加入此矩阵。
- 修改Skill后全量重跑，不只重跑失败项。
